# 定时多镜头剧本 · Timed Multishot Script

> 来源：2026-09-19 伙伴提供并实战验证的 30 秒七镜头剧本（秋日城市一天），本文提炼其可复用骨架。
> 定位：**剧本格式技能**。不教工具参数（那是 `seedance-25` 的活），只管「一段多镜头故事怎么写才不散」。

## 什么时候用

| 场景 | 用 |
|---|---|
| 一条 15–60s，覆盖 3–8 个镜头/场景 | ✅ 本技能 |
| 单镜头单场景（一个小动作/一个情绪） | ❌ 用 `seedance-25` 基础生成 |
| 30–180s 完整叙事弧（有起承转合） | ⚠️ 本技能写剧本，工具走 `seedance-25` 超长模式 |
| 短视频口播/带货脚本 | ❌ 用 `shortform-genesis` |

**判据**：用户的描述里出现「离开 A，走到 B，中间经过 C」这种**时间流 + 多地点**结构 → 本技能。出现单一动作 → 不用。

## 核心：14 栏骨架

按顺序写。**栏 1–3 必填，4–14 按需**，但多镜头片（≥5 镜）建议全上——省的每一栏都会在生成时变成漂移。

| # | 栏位 | 干什么 | 必填 |
|---|---|---|---|
| 1 | 场景背景 | 一句话故事线 + 总时长 + 形式定性（纪实/广告/剧情） | ✅ |
| 2 | 人物特征 / 参考图 | 外貌锁 + 穿搭锁 + `@image1` 参考声明 | ✅ |
| 3 | 格式模式 | 定时多镜头剪辑 + HARD CUT 时间轴清单 + 切换规则 | ✅ |
| 4 | 光学 & 镜头设定 | 逐镜头 FOV 角度 + 机位 + 运动方式 | ⭐ 强烈建议 |
| 5 | 动作与台词 | 逐镜头：画面动作 + 台词（或标注"无对白"） | ✅ |
| 6 | 表演要求 | 克制度、抓拍感、生理细节（高光/白气/质感） | ⭐ |
| 7 | 物理效果 | 材质世界的因果（落叶有重量、蒸汽上升、视差） | 按需 |
| 8 | 照明 | 逐镜头布光 | ⭐ |
| 9 | 调色 | 单一色调方案 + **排除项** | ⭐ |
| 10 | 服装 | 锁死主件 + 可变附件的边界 | 按需 |
| 11 | 音频 | 逐镜头环境音 + 对白策略 | ⭐ |
| 12 | 风格 | 胶片质感 / 焦段 / 颗粒 / 对焦行为 | ⭐ |
| 13 | 输出设定 | 分辨率 / 帧率 / 速度 / 运镜性质 | ✅ |
| 14 | 正向锁定要求 | 全局锁复述（身份/服装/时间戳/色调） | ✅ |

**为什么是这 14 栏而不是 5 栏**：多镜头片最大的失败模式是**跨镜头漂移**——第 3 镜毛衣变红，第 6 镜头发散了，第 7 镜色调冷了。每一栏都是对某一类漂移的封锁线。少写一栏 = 开一个漏口。

## 三个让这套格式「活」过来的设计

### ① 镜头编号贯穿网格（灵魂）

镜头 1–7 的编号必须在 **光学栏 / 运镜描述 / 动作栏 / 照明栏 / 音频栏** 五处**同步出现且编号对齐**。

```
光学：镜头 3：29° 人像压缩视角
运镜：镜头 3：从手部快速摇到脸部，再摇回手部的甩镜
动作：8.0s–12.0s：...递出现金，接过纸杯...
照明：镜头 3：阴天自然光，均匀柔和主光
音频：镜头 3：意式咖啡机嘶嘶声，简短对话
```

好处：改一个镜头时能一眼查全它的五个属性；模型读到时，五处重复强化归属，**漂移率显著下降**。这是这套格式最不可省的结构。

### ② 光线当叙事时钟

不要让照明栏变成逐镜头堆形容词。让**光线自己走完一天**：清晨低角度暖阳 → 地铁冷荧光 → 阴天散射 → 树冠斑驳 → 窗光漫射 → 黄金时刻轮廓光 → 夜晚路灯光带。

观众记不住第 4 镜用了什么光，但会感到「这一天过去了」。**照明栏 = 时间轴的第二条轨道**。

### ③ 有对白 / 无对白交替

B-roll 空镜（无对白）与对话镜头交替排布，是纪录片质感的来源。在动作栏显式写「无对白」——这**不是省略，是主动指令**（阻止模型给每个镜头都编台词）。

推荐节奏：有 → 无 → 有 → 无 → 无 → 有 → 有（2–3 个空镜打底）。

## 写作铁律

1. **时间戳连续且无缝**：`0–4 / 4–8 / 8–12...`，前一段的结束必须等于后一段的开始。禁止留空档。
2. **HARD CUT 只在你指定处发生**：开头和结尾的「格式模式」栏都要明写「仅在指定时间点硬切，镜头不会自动切换」。不写，模型会自作主张转场。
3. **调色栏必带排除项**：「不出现霓虹灯、不出现高饱和招牌、无冷青色、无洋红偏色」。排除项比正面描述更有效——尤其拍夜景时。
4. **台词越短越好**：一条 30 秒片里，总台词控制在一句话以内（或 2–3 个短句）。台词长了必然对口型崩坏。台词要写**口语**，不写书面语（"好吧——我们开始吧"✅ / "让我们启程"❌）。
5. **生理细节是真实感的锚**：眼睛里保留高光、呼出的白气、皮肤与织物纹理。这三条写进表演栏，性价比极高。
6. **全局锁在第 14 栏复述**：身份一致性、主服装件、色调、时间戳规则——**再写一遍**。重复不是啰嗦，是权重。
7. **`@image1` 不是装饰**：真给了参考图，它必须同时出现在第 2 栏（声明）和第 14 栏（锁定）。没给图时，明确写「人物一致性靠文字锁定，跨段会打折」——别假装有。

## ⚠️ 现实工程约束（实测踩过的坑）

| 约束 | 应对 |
|---|---|
| 单条生成常被限到 **4–12 秒**（提交 30s 会被直接拒绝） | 拆段生成（如 12+12+5s）→ ffmpeg concat 无损拼接 |
| 拆段后拼接边界**无法**保持原稿 0.5s 精度 | 提前告知用户「硬切点会从 7 个减到 5 个」，不假装还原 |
| 段间音轨各自独立 → 拼接有跳变 | 建议叠一层 BGM 盖过去 |
| 无参考图时跨段人物一致性打折 | 靠文字锁 + 建议用户补图重生成 |

**拼接顺序必须核对一遍**（2026-09-19 实踩：首版把书店排到了夜车之后，叙事不通，重拼）。拼接前对着剧本时间轴念一遍顺序。
