# 输出设定、全局锁定与投喂流程

## 输出设定栏（写作模板）

> 4K，24fps，带 35mm 胶片颗粒；除镜头 4 为半速慢动作外，其余均为实时速度；真实手持运镜；调色全程禁止霓虹光源、高饱和招牌。

四要素：

1. **分辨率 + 帧率**：4K / 24fps（电影感）｜1080p / 30fps（社交平台）
2. **胶片质感**：`带 35mm 胶片颗粒`
3. **速度例外**：哪个镜头是慢动作，其余声明为实时——**例外要单独点出**
4. **运镜性质**：真实手持 / 稳定器

---

## 风格栏（写作模板）

> 真实生活 Vlog 纪实摄影，35mm 电影质感，细腻自然胶片颗粒；真实自动对焦的轻微搜索感；对话镜头 + 无声抓拍混合，营造生活化、非剧本感。

关键那块是 **`真实自动对焦的轻微搜索感`**——这一点让画面从"渲染出来"变成"拍出来的"。同类的还有：轻微曝光呼吸、镜头边缘轻微暗角、偶发的手持重心变化。

---

## 全局锁定栏（第 14 栏）四锁结构

| 锁 | 内容 | 范例 |
|---|---|---|
| ① 身份锁 | 面部/体型跨镜头统一 + 参考图 | 和参考图 @image1 完全一致 |
| ② 服装锁 | 主件全程可见 + 发型 | 酒红色毛衣、银色项链全程可见；头发始终是同款松散高发髻 |
| ③ 规则锁 | 切换规则 + 无对白镜头 | 仅在指定时间点硬切，相机不会自动切换；镜头 2、5 保持无对白 |
| ④ 色调锁 | 色调 + 排除项 | 全程维持暖琥珀色调，画面不能出现霓虹、冷青色 |

**为什么必须复述**：这四条在正文里都出现过。重复是**加权**，不是啰嗦。多镜头片里，正文分散的约束在生成时会被稀释——收口再写一遍，是最便宜的保险。

## 投喂流程

### Step 1 · 先判定能不能一条出

| 平台能力 | 投喂方式 |
|---|---|
| 支持超长/多段一次生成（如即梦 Seedance 2.5 超长模式） | ✅ 整段投喂，剧本原样粘贴 |
| 单次上限 4–12 秒 | ⚠️ 必须拆段：按剧本时间轴切成 2–3 段 |

**实测教训**：30 秒整段提交会被直接拒绝（限流提示）。别浪费一次尝试，先查平台时长上限。

### Step 2 · 拆段原则

- 每段 5–12 秒，**切点落在 HARD CUT 上**（本来就是硬切点，最自然）
- 每段都**重复带上**：人物特征栏 + 服装锁 + 调色锁（跨段一致性全靠这个）
- 保留该段的光学/运镜/照明/音频四栏描述

### Step 3 · 拼接与核对

```bash
# 参数一致性检查（必须完全一致才能无损 concat）
ffprobe -v error -select_streams v -show_entries stream=codec_name,width,height,r_frame_rate -of csv=p=0 段1.mp4

# 无损拼接
ffmpeg -f concat -safe 0 -i list.txt -c copy 成片.mp4
```

> **拼接前对着剧本时间轴念一遍顺序。** 2026-09-19 实踩：首版把「书店」排到了「夜车」之后，叙事不通，重拼一次。这个错很低级但极易犯。

### Step 4 · 验证

```bash
ffprobe -v error -show_entries format=duration -show_entries stream=codec_type -of csv=p=0 成片.mp4
```

确认：**视频轨 + 音轨都在**、总时长接近目标。

## 交付时必须如实说明的三件事

1. **段间音频会跳变**（各段独立生成）→ 建议叠 BGM
2. **拼接边界无法保持原稿的精确切点**（7 个切点变 5 个，要主动告知）
3. **没有参考图时，人物一致性靠文字锁，跨段会打折**——不要假装有 `@image1`

按 `verify-before-delivery` 的规矩：没验证的不说"已完成"。
