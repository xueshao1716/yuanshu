# 镜头光学与运镜库

## FOV 角度速配表（这套格式的核心量化维度）

用**视场角**而不是"广角/长焦"来形容，模型理解得更精确。

| 角度 | 等效焦段 | 情绪效果 | 适合 |
|---|---|---|---|
| **63°** | ~28mm 广角 | 环境优先、人在场景里 | POV 第一人称、场景交代、空间窒息感 |
| **47°** | ~40mm 标准 | 中性、不干预 | 双人镜头、旁观视角、客观记录 |
| **29°** | ~50–58mm 人像压缩 | 微聚焦、略抽离 | 人物半身、动作特写（手→脸） |
| **18°** | ~85mm 长焦 | 亲密、压缩背景、情绪放大 | 特写、情绪反思、慢动作细节 |

> 范例排布：63°（POV 出门）→ 47°（地铁旁观）→ 29°（咖啡摊甩镜）→ 18°（落叶慢动作）→ 29°（书店抓拍）→ 47°（屋顶举杯）→ 18°（夜车情绪）

**规律**：角度在片中做**呼吸式变化**（广→中→窄→中→窄），不要一直用同一档，也不要乱跳。

## 运镜手法库

每镜头写「机位 + 运动速度 + 附加质感」三段式。

| 手法 | 写法 | 用途 |
|---|---|---|
| **POV 行走** | 手机高度 POV 视角，以 4km/h 速度向前行走 | 代入感开场 |
| **倚靠旁观** | 相机低位靠在立柱上，几乎无移动，旁观式视角 | 抓拍/纪实 |
| **甩镜** | 从手部快速摇到脸部，再摇回手部的甩镜 | 交易、快节奏动作 |
| **横向跟拍** | 半速慢动作，相机以 1km/h 横向跟拍落叶 | 氛围 B-roll |
| **偶遇延迟** | 相机仿佛偶然拍到她，在她发现镜头前有轻微延迟 | 未察觉抓拍（关键） |
| **固定等入画** | 近乎静止、有支撑固定，人物走入画面 | 稳定落点 |
| **隔物拍摄** | 透过汽车车窗静止拍摄，光影倒影掠过她的脸庞 | 情绪收束 |

### 手持抖动的分级

- 全片统一基础量：`全程手持拍摄，带有 1–2 厘米自然轻微抖动`
- 需要更稳的镜头（如镜头 6）：`近乎静止、有支撑固定`
- **一定加一句** `片段画面无画面漂移`——防画面内容漂移（与手持抖动不是一回事）

## 常见组合配方

- **生活纪实**：POV 行走 → 倚靠旁观 → 固定等入画 → 隔物拍摄
- **旅行 Vlog**：POV 行走 → 甩镜扫景 → 横向跟拍 → 偶遇延迟
- **品牌生活流**：固定等入画 → 18° 特写产品手部 → 47° 人物使用 → 63° 环境收尾

---

## 反例

- ❌ 「用各种镜头拍她的一天」→ 没有归属，模型随机
- ❌ 7 个镜头全用 63° 广角 → 平，无节奏
- ❌ 每镜都写"快速摇镜+推轨+升降" → 装饰性运镜，注意力被机位本身抢走
- ✅ 一个镜头一种运动，让相机**服务那个镜头要交代的变化**
