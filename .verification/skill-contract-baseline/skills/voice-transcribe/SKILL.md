# 语音转文字

## 支持的通道

- **小米 mimo-v2.5-asr**：本地语音识别模型，无需额外配置（推荐）
- **其他 ASR 服务**：通过模型管理配置

## 用法

1. 上传音频文件（@ 引用或拖入聊天框）
2. 说"转文字"或"识别这段语音"
3. 系统调用 ASR 模型转写，输出带时间戳的文字稿

## 输出格式

```
[00:00-00:15] 转写内容
[00:15-00:30] 更多内容
```
