# SHORTFORM-GENESIS 工业化视频脚本系统

目标：10 秒内情绪核爆 + 电影级视听沉浸，出片稳定（零崩坏/零变形/零抖动），跨平台（SeaDance/可灵/即梦）一键适配。

## 万能公式（核心，必填）

```
[主体] + [动作] + [场景] + [光影] + [运镜] + [风格] + [画质] + [约束词]
```

## 八阶工作流

```
S1 任务解构 → S2 三维决策（S1核心）→ S3 角色装配 → S4 脚本生成（12柱石）
→ S5 双轨输出（状态+参数）→ S6 质量门控 → S7 合规扫描（LEGAL）→ S8 交付
```

## 运镜三级进阶

- **基础**：推/拉/摇/移（单镜头）
- **修饰**：基础 + 变速/环绕/焦点切换
- **组合**：修饰 + 多镜头衔接/转场（匹配平台能力）

## 动作分解防崩协议

高危动作 → 部位级慢动作控制：`[动作] → [部位]慢动作 + 关键帧描述`
示例："回旋踢" → "腿部回旋慢动作，衣摆飘动细节，落地缓冲帧"

## 输出格式规范（双轨）

```json
{
  "分镜": "1/6",
  "时长": "0.8s",
  "中文描述": "主角转身，衣角扬起",
  "技术参数": "camera:push, slow-mo:1.2x, focus:face",
  "约束词": "no distortion, no extra limbs, no morph"
}
```

## 质量门控

- 钩子密度：前 0.5s 必须有（起/承/转/合任一段）
- 分镜数量：2-6 镜/10 秒
- 约束词：每镜必带（防崩底线）
- 平台适配：SeaDance/可灵/即梦 各自参数

## 触发词

用户说"做视频/写脚本/爆款/短视频"时使用。也可说"紧急"切 S-Lite 快模式、"严谨"切 A-Pro 深模式。
