# 会话导出脱敏

pi-web 内置的导出功能已自动脱敏：

- **HTML 导出**：消息文本中的 sk-xxx / token / 密码自动替换为 `***[已脱敏]`
- **JSONL 导出**：逐条脱敏，保留会话结构

## 用法

在会话中直接说"导出当前会话"或使用导出按钮。

## 验证

导出后检查文件，确认没有 `sk-`、`love#`、长串 token 等字样。
