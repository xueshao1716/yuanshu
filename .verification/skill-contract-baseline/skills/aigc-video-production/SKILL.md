# AIGC 视频生产工作流

融合《Hell Grind》95 分钟开源 AI 电影方法论：十阶段项目管理 + 图片/视频提示词专业结构。模型无关，适配任意平台。

## 使用流程

1. **分类请求**：按工作流（项目管理/图片提示词/视频提示词）+ 丰富度（精简/标准/导演版）分类
2. **提取意图**：原始意图、硬约束、参考范围、输出用途、未决选择
3. **只问关键问题**：缺失信息会实质改变结果才问，否则给保守假设
4. **分层输出**：平台无关主提示词 + 平台适配层分离
5. **验证**：ID、引用、连续性、提示词完整性、矛盾、交付门槛

## 十阶段项目管理

| 阶段 | 核心产物 | 退出条件 |
|---|---|---|
| 00_brief | 项目配置/brief | 受众/时长/画幅/硬约束/预算明确 |
| 01_story | 故事圣经 | 世界规则/角色弧光/视觉母题可检查 |
| 02_assets | 资产表+参考图 | 角色/道具/场景有稳定 ID 与批准版本 |
| 03_scenes | 场次表 | 顺序/地点/时间/故事目标明确 |
| 04_shots | 镜头表 | 唯一 ID/时长/目的/动作接点 |
| 05_prompts | 版本化提示词 | 主提示词/适配层/假设/负面约束分离 |
| 06_generations | 生成记录 | 每次尝试可回溯到镜头/提示词/参数/成本 |
| 07_review | 选片+连续性 | 选择理由/缺陷/连续性可追溯 |
| 08_edit | 时间线+剪辑说明 | 画面/声音/字幕/转场/调色明确 |
| 09_delivery | 交付检查表 | 技术/内容/权利/归档/发布授权完成 |

**镜头状态**：planned → prompt_ready → generated → reviewed → selected → locked（返工记录原因，不覆盖旧版本）

## 图片提示词 11 类结构

1. **主体与数量**：恰好出现谁/多少个
2. **身份锚点**：稳定 ID/年龄段/体型/脸型/发型（不随镜头变）
3. **外观状态**：服装版本/伤势/污渍/妆发（当前画面）
4. **动作姿态**：重心/手脚位置/视线/接触/动作瞬间
5. **场景空间**：地点 ID/时间/布局/前后景/环境锚点
6. **构图机位**：景别/角度/机位高度/主体占比/留白
7. **镜头语言**：焦段感/景深/对焦对象/透视（不只写"电影感"）
8. **光线曝光**：主光源/方向/软硬/对比/轮廓光
9. **色彩材质**：主辅强调色/材质/磨损/反射（60:30:10）
10. **风格媒介**：摄影/插画/动画/概念设计语言
11. **技术与负面**：画幅/用途/高风险禁止项（额外人物/错字/重复肢体/漂浮道具）

## 视频提示词 12 段镜头契约

1. **镜头目标与叙事功能**：观众需理解/感受/发现什么
2. **精确角色数量与稳定 ID**：恰好出现的人物/生物
3. **当前外观与状态**：服装/伤势/手持物/开始状态
4. **场景空间与唯一道具**：地点 ID/布局/站位/尺度/出入口
5. **动作时间线**：起始—过程—结束（或秒数拆解）
6. **摄影机契约**：起始构图/机位/焦段/路径/速度/对焦/结束构图
7. **光线色彩天气**：光源/对比/60:30:10 色彩/材质反应/天气
8. **表演视线物理**：情绪译成微动作/重量/惯性/接触
9. **连续性**：身份/轴线/屏幕方向/动作接点/服装/伤势/道具
10. **对白与声音**：说话者/逐字台词/起止/环境音/音效/配乐/字幕
11. **针对性负面约束**：身份漂移/额外人物/错误口型/抖动/烧录字幕
12. **交付规格**：时长/帧率/画幅/分辨率/用途

**冲突处理**：一次镜头一个主要摄影机运动；动作服从时长；"自然手持"≠随机抖动；对白留真实发声时间。

## 提示词意图保护

- **约束账本**：原始意图/硬约束/可增强/歧义/缺失
- 硬约束（身份数量/动作结果/逐字对白/画幅/用途/禁止项）**润色时不得静默改变**
- 抽象词 → 可见可听可计时可检查的描述（"悲伤"→"视线落地、肩膀微收、眼眶含泪"）
- 主提示词模型无关，平台参数（采样器/步数/参考权重）放适配层

## 三种丰富度

- **精简版**：最少必要结构，快速试验
- **标准版**：完整视觉/镜头契约，控制长度
- **导演版**：时间线/表演/物理/声音/连续性/验收细节

## 质量门槛（交付前）

- 主体数量无歧义、身份 ID 一致、连续性无矛盾
- 提示词完整（11 类/12 段无空缺）
- 硬约束全部保留、负面约束针对性
- 主提示词与平台适配层分离
