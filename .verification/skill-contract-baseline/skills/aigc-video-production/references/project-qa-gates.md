# 项目质量门

## 结构门

- 十阶段目录和必需文件存在。
- CSV 表头完整，ID 格式正确且无重复。
- 场景、镜头、生成、选择和连续性引用都能解析。
- 项目配置含项目 ID、名称、日期、画幅和状态。

先运行：

```bash
python3 scripts/validate_project.py /absolute/project/path --json
```

该脚本只检查结构和引用，不观看媒体，也不修改项目。

## 创意门

- 每个镜头都有清晰叙事功能，不只是“电影感”。
- 人物、生物、道具和地点均来自批准资产。
- 动作节拍能在镜头时长内完成。
- 起始构图、摄影机路径和结束构图不互相冲突。

## 连续性门

- 精确人数、身份、服装、伤势和道具位置一致。
- 屏幕方向、轴线、视线和动作接点一致。
- 时间、天气、光源和环境破坏状态一致。
- 对白说话者、口型、静默尾拍、字幕和配乐边界一致。

## 生成记录门

- 每次生成有唯一 ID、镜头 ID、提示词版本、模型和时间。
- 记录种子或可用的复现参数、成本和失败原因。
- 选片记录说明接受了什么、拒绝了什么、为何选择。

## 交付门

- 成片规格与 brief 一致。
- 技术问题和创意豁免有明确负责人和记录。
- 原始参考、生成结果、声音、字体和发布平台的权利边界已确认。
- 发布行为获得独立授权；“提示词完成”不等于“允许上传”。
