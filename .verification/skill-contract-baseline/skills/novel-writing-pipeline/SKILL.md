# 小说写作管道

四源融合（Autonovel × InkOS × Claude Code Routines × novel-forge），面向中文网文长篇。

## 四阶段管线

```
Phase 1: 基础构建 → 5层生成+评分循环
Phase 2: 逐章写作 → 快照→生成→免疫→审计→修改
Phase 3: 多轮修订 → 对抗编辑+读者面板+高阶审稿
Phase 4: 导出 → 整合+发布
```

## 5 层共进化架构

> ⚠️ 下面这 5 个 `.md` 是**运行时产物**：由你在用户的小说工程目录里创建和维护，**不在本技能目录里**，不要去 `skills/` 下找它们。工程根目录记作 `BOOK_ROOT`。

| 层 | 文件 | 内容 | 改动的连锁 |
|---|---|---|---|
| L1 | voice.md | 叙事声音（文风/语气/视角） | → 重校 L2-L5 |
| L2 | world.md | 世界观（地理/历史/势力/规则） | → 重校 L3-L5 |
| L3 | characters.md | 人物（主角/配角/性格弧线） | → 重校 L4-L5 |
| L4 | outline.md | 大纲+伏笔（章节规划/伏笔网络） | → 重校 L5 |
| L5 | canon.md | 硬事实数据库（不可违背的事实） | — |

**原则**：任何一层改动，必须重校下游所有层的一致性。

## 7+1 真相文件系统（BOOK_ROOT/TRUTH/）

- `current_state.json` — 世界状态（角色位置/关系/局势）
- `particle_ledger.json` — 资源账本（物品/金钱追踪）
- `pending_hooks.json` — 未闭合伏笔
- `chapter_summaries.json` — 各章摘要
- `subplot_board.json` — 支线剧情追踪
- `emotional_arcs.json` — 情感弧线记录
- `character_matrix.json` — 角色信息边界（谁知道什么）
- `canon.md` (+1) — 硬事实数据库（不可违背）

**写每一章前读真相文件，写完后更新真相文件。** 这是长篇防跑偏的关键。

## 26 维审计（7 层，纯规则零 LLM 成本）

| 层 | 维度 | 检测 |
|---|---|---|
| 设定层(4) | OOC/时间线/设定冲突/伏笔回收 | 角色行为/时间矛盾/规则冲突 |
| 叙事层(4) | 节奏/文风/信息越界/词汇疲劳 | 拖沓/视角混/越界知识/高频词 |
| 逻辑层(4) | 利益链/爽点/战力/数值 | 动机/铺垫/实力/数字矛盾 |
| AI味层(4) | 段落等长/套话/公式化转折/列表 | AI痕迹 |
| 配角层(3) | 降智/工具人/对话同质 | 配角智商/独立性/风格差异 |
| 情感层(3) | 弧线断裂/情绪乱跳/动机不足 | 情感逻辑 |
| 网文层(4) | 爽点密度/金手指/代入感/章末钩 | 网文特有指标 |

## 题材规则（4 套内置）

- **xianxia.json** 玄幻：修炼体系/战力值/法宝丹药
- **urban.json** 都市：人际关系/商业逻辑/年代考据
- **horror.json** 恐怖：氛围营造/禁忌/恐惧递进
- **scifi.json** 科幻：科技设定/逻辑自洽

每套含：禁忌清单、疲劳词、语言铁律、章节类型、节奏规则。

## 双重免疫（AI 味检测）

1. **正则免疫**（零成本）：Tier1/2/3 禁词 + 网文特定 AI 痕迹 + 结构检查（段落等长/三段排比/对话质量）
2. **对抗编辑**（LLM）：让模型找 10-15 处可删段落，分类 FAT/REDUNDANT/OVER-EXPLAIN/GENERIC/TELL/STRUCTURAL——删什么暴露什么最弱

## 写章流程（每章）

1. 读真相文件（7+1）→ 读本章大纲 → 读角色卡
2. 写前快照（可回滚）
3. 生成章节（带题材规则约束）
4. 免疫扫描（正则，零成本）
5. 26 维审计 → 定位问题
6. 针对性修改（只改有问题的维）
7. 更新真相文件（状态/伏笔/资源/摘要）
8. 章末钩（网文必须有）

## 网文写作要点

- **章末钩**：每章结尾留悬念/期待
- **爽点密度**：每章至少 1-2 个情绪释放点
- **金手指**：主角的核心优势，四维约束（来源/限制/成长/代价）
- **代入感**：主角视角为主，动机清晰
- **对话**：有性格差异，不全员同声
- **防跑偏**：跨大境界战力不崩、资源不无限、伏笔不丢
