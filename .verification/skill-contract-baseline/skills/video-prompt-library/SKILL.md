# 短视频赛道爆火提示词库

来源：船长AI短剧知识内容《各类短视频赛道爆火提示词专家》（飞书文档，2026-09 归档自 PDF，215 页）。
32 套模板，每套含完整角色设定 + 提示词工程结构，面向 AI 视频生成工具（即梦 / Sora / Veo / 可灵 / Runway）与 AI 生图工具。

## 使用方法

1. 按用户意图选赛道（下方分组表），读对应 `references/` 文件
2. 模板中的**主体/场景/风格变量**替换为用户需求
3. 输出完整提示词；目标工具的时长/画幅/运镜参数按需适配
4. 相邻赛道可组合（如「微缩模型」×「灾难救援」出微缩救援现场）
