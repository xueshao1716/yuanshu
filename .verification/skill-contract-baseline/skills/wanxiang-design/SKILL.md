# 万像平面设计提示词系统

把专业设计知识（网格 / 字体 / 色彩 / 构图）编码成 AI 可执行的指令集，产出**纯净自然语言提示词**。
本文件是执行入口：坐标与参数速查 + **章节索引** + 输出契约 + 本机出图通路。

## 输出契约（每次都要满足）

1. **只输出提示词本身**，禁止内部编号/函数/程序脚本语言。
2. **不留占位符** `{xxx}`——关键字段必须填具体值。
3. **符号只用** `, . " + ( ) # -`；角度写汉字"度"（不写 `°`）；所有符号用英文半角。
4. 冒号 `:` 只用于参数值之前（如 `ivory_tone（L75 a+3，细腻通透）`）。
5. 允许并鼓励**跨章节调用**技术方案（颜色章 + 文字章 + 构图章可以一起用）。
6. 交付前自检：坐标是否对齐需求、留白是否达标、色彩是否协调（见下面"自检"）。

## 设计控制三维坐标系（先定位，再生成）

任何设计先用三维坐标定位风格：

| 维度 | 范围 | 含义 |
|---|---|---|
| **X 商业-艺术** | 0-100 | 0=纯艺术 / 50=平衡 / 100=纯商业（转化优先） |
| **Y 传统-实验** | 0-100 | 0=经典 / 50=融合（新中式）/ 100=前卫实验 |
| **Z 简约-复杂** | 0-100 | 0=极简（大量留白）/ 50=丰富 / 100=信息密集 |

坐标 → 指令（示例）：
- 高端文化海报 `[X:30,Y:40,Z:20]` → elegant cultural poster, minimalist layout, traditional modern fusion, ample white space, sophisticated typography（负向：no commercial, no vibrant, no crowded）
- 科技品牌概念图 `[X:70,Y:80,Z:60]` → tech conceptual, futuristic, complex details, glowing elements
- 电商促销 Banner `[X:90,Y:20,Z:70]` → e-commerce banner, high contrast, clear CTA, product focus（负向：no artistic ambiguity, no subtle colors）

## 参数速查（摘要，够日常用）

- **东方美学三核心**：留白意境（留白 40-60%、单一焦点）/ 水墨韵律（墨色 5-8 阶、宣纸纹理）/ 对称平衡（不对称对称、阴阳构图）。
- **极简公式**：核心元素 ≤3、色彩 ≤3、字体 ≤2、留白率 ≥40%。
- **东方五色**：赤 #C53A3A（热情/吉祥）/ 青（清雅）/ 黄（尊贵）/ 白（空灵）/ 黑（沉稳）；**60:30:10** 比例（主/辅/强调）。
- **文字系统**：字体 ≤2（标题+正文）；标题衬线=古典、无衬线=现代、书法=东方；层级 主标题→副标题→正文→辅助信息（字号递减）。
- **品牌视觉基因座**：标志/色彩/字体/辅助图形/版式 5 要素统一；名片/海报/包装/网页沿用同一基因。
- **启动机制（原文规定）**：第一次启动立即输出提示词结果，基本样式以第十六章的示例为准。

## 使用流程

1. **定位**：问清设计类型（海报/Banner/品牌/包装/名片）+ 目标（转化/品牌/艺术）+ 平台。
2. **三维坐标**：定 X/Y/Z → 得到风格基调与负向控制。
3. **美学选择**：东方三核心 / 极简 / 其他（按坐标）。
4. **色彩**：选情感色 + 60:30:10 比例。
5. **文字**：定字体对 + 信息层级。
6. **输出**：正向指令 + 负向控制（JSON-like 或自然语言）。
7. **自检**：坐标是否对齐需求？留白是否达标？色彩是否和谐？字体是否 ≤2？
8. 需要模板/案例/完整体系时，按 `INDEX.md` 行号读原文对应章节。
9. 要真出图就用本机通路（下一节）。

## 本机出图通路（元枢）

提示词写好后可以直接出图，走元枢自己的通路，**不要**自己 curl 上游、不要读 `.token`：

- 在对话里说「画一张…」/「配图」，或调用 `generate_image`；
- 通路实现是 `engine/media-api.mjs` 的 `generateImage`（产物按本地化契约落进工作空间）；
- 本机实际可用的图像模型是 `agnes-image-2.0-flash / 2.1-flash / 2.5-flash`。
  原文里的 MJ/SD/即梦语法是**提示词写法参考**，不是本机能直接调的平台。

## 常见失败（踩过就别再踩）

- **只给风格形容词、不给版式结构** → 平面设计的关键是版式（网格/层级/留白/对齐），要给结构指令。
- **字体给到 3 种以上** → 信息层级会糊掉；标题+正文两种足够，剩下靠字号与字重拉开。
- **色彩比例缺失** → 只写"红金配色"很容易出成一片大红；写清 60:30:10。
- **把设计当插画写** → 设计要有明确的信息主体与阅读顺序，插画式的"氛围描述"会把版式冲掉。
- **要准确的中文字** → 生成模型的中文常常写错；标题字多的场合，先出**无字底图**再叠字。
