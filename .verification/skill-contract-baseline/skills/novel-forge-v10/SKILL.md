# 小说锻造炉 v10

> 融合 v1（基础管道）× v2（四源融合）× v3（零成本审计）× v4（产品思维）× v8（clean-arch）× v9（智能子系统：编辑部 COORD / 灵魂系统 / 元认知 FixHint / SQLite 知识层）
> 核心哲学：**先想清楚卖给谁，再动笔；写得好不如卖得对。**

## 产品化初始化（动笔前必做，来自 v4）

1. **市场雷达**：查当前题材趋势（起点/番茄热榜），判断要写的题材有没有市场
2. **读者画像**：这本书给谁看？爽点偏好？阅读场景？
3. **产品定位**：一句话说清卖点（"反套路修仙+系统文+轻松向"）
4. **差异化**：同类书里我的差异点是什么

## 四阶段管线

```
Phase 0: 产品化初始化 → 市场雷达 + 读者画像 + 卖点定位
Phase 1: 基础构建 → 5层生成 + 评分循环
Phase 2: 逐章写作 → 快照 → 生成 → 免疫 → 审计 → 修改
Phase 3: 多轮修订 → 对抗编辑 + 读者仿真 + 高阶审稿
Phase 4: 导出 → 整合 + 发布
```

## 5 层共进化（来自 v2）

> ⚠️ 下面这 5 个 `.md` 是**运行时产物**：由你在用户的小说工程目录里创建和维护，**不在本技能目录里**，不要去 `skills/` 下找它们。工程根目录记作 `BOOK_ROOT`。

| 层 | 文件 | 内容 | 改动连锁 |
|---|---|---|---|
| L1 | voice.md | 叙事声音（文风/语气/视角） | → 重校 L2-L5 |
| L2 | world.md | 世界观（地理/历史/势力/规则） | → 重校 L3-L5 |
| L3 | characters.md | 人物（主角/配角/性格弧线） | → 重校 L4-L5 |
| L4 | outline.md | 大纲+伏笔（章节规划/伏笔网络） | → 重校 L5 |
| L5 | canon.md | 硬事实数据库（不可违背的事实） | — |

**任何层改动，必须重校下游所有层一致性。**

## 7+1 真相文件系统（BOOK_ROOT/TRUTH/，运行时产物）

`BOOK_ROOT/TRUTH/` 下：
- `current_state.json` 世界状态
- `particle_ledger.json` 资源账本（物品/金钱/修为追踪）
- `pending_hooks.json` 未闭合伏笔
- `chapter_summaries.json` 各章摘要
- `subplot_board.json` 支线剧情追踪
- `emotional_arcs.json` 情感弧线
- `character_matrix.json` 角色信息边界（谁知道什么）
- `canon.md` 硬事实库（不可违背）

**写前读，写后更新。** 这是长篇防跑偏的根本。

## 编辑部 8 角色协作（来自 v9 实现，含 COORD 调度）

写每章时 8 个角色分工（v9 已真 LLM 验收：standard 预设 9 次调用/2468 字/LOGIC 真捕获时间线 bug）：

| 角色 | 阶段 | 职责 |
|---|---|---|
| **COORD** | S0 | 调度者：分解章节意图 → 选协作模式 → 装配角色 |
| IDEA | S1 | 出创意（×3 备选并行） |
| EXEC | S2 | 执行写作（出初稿） |
| CHALLENGE | S3 | 攻击性质疑（≥5 条，并行） |
| FACT | S3 | 事实核查（对真相文件/知识库，并行） |
| LOGIC | S3 | 逻辑审计（时间线/因果链，并行） |
| ORCHE | S4 | 统筹定稿（串行） |
| HUMAN | S5 | 人性化终稿（去 AI 味+风格锁定，串行） |

**并行**：IDEA 3 版并行；CHALLENGE + FACT + LOGIC 并行。ORCHE/HUMAN 串行。

### 三维决策矩阵（preset：fast / standard / deep）

| 维度 | 快 fast | 标准 standard | 深 deep |
|---|---|---|---|
| 协作模式 | S 简化（只 EXEC+HUMAN） | B 直接（8 角色标准链） | A 中心化（COORD 逐轮仲裁） |
| 验证级别 | Lite（跳过 FACT/LOGIC） | Standard（3 review 齐上） | Pro（+ reader_panel + 二轮 CHALLENGE） |
| 能力增强 | Lite（不注 soul） | Standard（注主角 soul） | Pro（全角色 soul + genre 特化） |

**元认知失衡时 COORD 可换 preset（见元认知 FixHint）。**

## 灵魂系统（SoulSymbiont，来自 v9 实现）

每个重要角色建灵魂档案 `souls/<char_name>.json`，四件套：

```json
{
  "wound_core": {"event": "父亲车祸时他在游戏机厅", "age": 12, "body_memory": "游戏机音效引发心悸", "repeat_pattern": "回避冲突"},
  "yearning_engine": {"surface": "变强", "deep": "被承认存在", "fear_admit": "承认自己脆弱"},
  "mask_construction": {"outer": "冷酷学霸", "behavior": "少说话多观察", "language_fingerprint": "用问句反弹"},
  "evolution_drive": {"stage": "试探", "next_stage": "连接", "trigger_needed": "遇到能看穿面具的人"}
}
```

**注入方式**：在 IDEA/EXEC 的 prompt 里追加 `{soul_context}`，用自然语言描述角色灵魂（不暴露 JSON）。

### 三大基因库（写人物/世界时的灵感引擎）

**情绪基因 EMOTION_GENES（5 类）**：
- `physical_resonance` 身体先于认知——恐惧先到胃里、愤怒先到下颌；身体反应比心理描写早半拍
- `trauma_echo` 旧伤在新情境回响——同样的气味/语气/光线瞬间拉回当年；瞬间失焦/身体僵直/过度反应
- `shadow_emergence` 阴影浮现——被压抑的自我（贪婪/嫉妒/暴力欲）在压力下浮出，做出连自己都吓到的事
- `relational_bonding` 关系五阶段——封闭→试探→连接→依赖→共生；倒退和跳跃都会出问题
- `existential_crisis` 存在危机五阶段——否认→愤怒→讨价还价→抑郁→接受；跳过任何一段都假

**灵魂基因 SOUL_GENES（4 件套）**——对应四件套的触发器/表达形态：创伤内核（回避/过度警觉）、渴望驱动（口头目标与行为对不上）、面具构建（标准化开场白+语言指纹）、演化驱动（行为模式松动/新词混入语言指纹）。

**世界基因 WORLD_GENES（3 类）**：
- `fate_structure` 命运骨架（高刚性）——出身/时代/体制像铁轨，提供不可协商的压力
- `chaos_field` 混沌域（高柔性）——偶然/意外/他人选择，防叙事变宿命论
- `collective_unconscious` 集体潜意识——群体共享的恐惧/渴望/道德直觉，"大家都这么选"的羞耻感

## 26 维审计（来自 v2/v3，零 LLM 成本优先）

| 层 | 维度 | 检测 |
|---|---|---|
| 设定层(4) | OOC/时间线/设定冲突/伏笔回收 | 角色行为/时间/规则/伏笔 |
| 叙事层(4) | 节奏/文风/信息越界/词汇疲劳 | 拖沓/视角混/越界/高频词 |
| 逻辑层(4) | 利益链/爽点/战力/数值 | 动机/铺垫/实力/数字 |
| AI味层(4) | 段落等长/套话/公式转折/列表 | AI痕迹 |
| 配角层(3) | 降智/工具人/对话同质 | 配角智商/独立性/风格 |
| 情感层(3) | 弧线断裂/情绪乱跳/动机不足 | 情感逻辑 |
| 网文层(4) | 爽点密度/金手指/代入感/章末钩 | 网文特有 |

**优先级**：先用正则零成本扫（免疫），再 LLM 深审关键维度。

## 双重免疫（来自 v2/v3）

1. **正则免疫**（零成本）：Tier1/2/3 禁词 + 网文 AI 痕迹 + 结构检查（段落等长/三段排比/对话质量）
2. **对抗编辑**（LLM）：找 10-15 处可删段落，分类 FAT/REDUNDANT/OVER-EXPLAIN/GENERIC/TELL/STRUCTURAL——删什么暴露什么最弱

### 中文 AI 味词表（具体禁词，来自 novel-forge-fusion）

**Tier 1 禁词（零容忍）**：`不禁`、`不由自主`、`不由得`、`倘若`、`纵然`、`纵使`、`弥漫着`、`笼罩着`、`宛如`、`恰似`

**网文 AI 痕迹（检测并改写）**：
| 部位 | 痕迹 |
|---|---|
| 眼睛 | `乌黑长发如瀑布般倾泻`、`深邃的目光` |
| 呼吸 | `长舒了一口气`、`倒吸了一口凉气` |
| 心跳 | `心跳到了嗓子眼`、`心脏像要从胸口跳出来` |
| 沉默 | `空气像是凝固了`、`死一般的沉默` |
| 震惊 | `瞳孔骤缩` |

**中文段落均匀度**：CV 阈值用 0.15（不是英文的 0.25）——中文段落长度变化天然小，阈值要紧避免误报。

**中文引号坑**：Python 字符串里中文引号 `"..."` 与 `"` 定界符冲突，用单引号 `'...'` 或 `\u201c`/`\u201d` 转义。

## 读者仿真（来自 v4）

用 LLM 扮演目标读者读一章，反馈：
- 读到这里想不想继续？为什么？
- 哪段最爽/最想跳过？
- 主角动机信不信？
- 会不会弃书？在哪弃的？

### Reader Panel 具体实现（3 读者角色，来自 novel-forge-fusion）

三个读者角色评估全书：
| 角色 | 关注 |
|---|---|
| **Editor** | 文笔质量、声音一致性 |
| **Genre reader** | 节奏、世界观、翻页性 |
| **First reader** | 情感体验、会不会推荐 |

**关键洞察**：读者之间的**分歧点 = 编辑决策所在**——分歧处就是最需要作者判断的地方。

## 元认知检查（来自 v9 实现：4 类失衡 + FixHint）

**输入**：26 维审计结果 → 检测失衡 → 输出修复指令 `{role_to_recall, prompt_variant, extra_context}`

| 失衡类型 | 症状 | FixHint |
|---|---|---|
| `OUTPUT_VOLUME_LOW` 字数不足 | 章节远低于目标 | 召回 **EXEC**，变体 `expand_scenes`（目标 ×1.3） |
| `CHARACTER_DEPTH_SHALLOW` 角色浅表 | 行为公式化 | 召回 **IDEA**，变体 `deepen_character`（soul_depth=pro） |
| `INTEGRATION_LOW` 情节人物脱节 | 剧情与人设两条线 | 召回 **ORCHE**，变体 `resync_plot_character` |
| `RUMINATION_STUCK` 反复无进展 | 同一处改三轮 | 召回 **COORD**，变体 `mutate_preset`（换 deep 预设） |

**防走过场**：过审（每章满分=没认真审）/ 欠审（关键维度没查）/ 视角失衡（全主角视角）/ 修订耗尽（改三轮同一处=该换策略）。

## SQLite 知识层（来自 v9 实现）

真相文件的机器可查版本，4 张表：

- `characters` — 角色（first/last chapter、soul_json、存活状态）
- `foreshadowings` — 伏笔账本（planted/paid_off 章节、open/paid/abandoned）
- `timeline` — 时间线（章节、事件、故事内时间、地点、涉及角色）
- `relationships` — 关系网（a-b-kind：enemy/lover/ally/mentor，since_chapter）

**填充**：每章后从观察结果 ingest 到 4 表（角色/伏笔/时间线/关系）
**查询**：`who_alive_at(chapter)` / `open_foreshadowings_before(chapter)` / `relationships_of(name)`——给 IDEA/EXEC/FACT/LOGIC 用，防伏笔丢失/时间线矛盾/关系遗忘

## 题材规则（4 套内置 + 可扩展）

- **xianxia** 玄幻（修炼体系/战力/法宝丹药）
- **urban** 都市（人际/商业/年代考据）
- **horror** 恐怖（氛围/禁忌/恐惧递进）

每套含：禁忌清单、疲劳词、语言铁律、章节类型、节奏规则。

## 技法库（写作质量精华，来自 v3/v4 guides）

### 章节开头（前 20% 决定生死）

**前 20% 必须达到**：即时紧张感 / 重大事件 / 情感冲击 / 继续阅读的欲望。

**开头致命错误（绝对避免）**：
| 错误 | 示例 | 为什么致命 |
|---|---|---|
| 天气描写 | "那天天气晴朗" | 与故事无关 |
| 日常流程 | "刷牙洗脸吃早餐" | 无聊没冲突 |
| 回顾上章 | "上一章我们说到" | 读者已知 |
| 缓慢铺垫 | "先介绍城市背景" | 信息倾倒 |
| 平淡对话 | "你好，你好吗" | 无张力 |
| 过度解释 | "这是因为所以" | 讲述非展示 |

**十种强力开头**（选一）：行动中开场（In Media Res）/ 对话冲突开场 / 悬念疑问开场 / 反常细节开场 / 紧迫倒计时 / 视角冲击 / 环境压迫 / 历史回响 / 秘密暗示 / 命运转折。

### 章节结尾（钩子十三式）

每章结尾必须有钩子，核心技巧：
1. **突然揭示**——结尾揭示改变一切的信息
2. **紧急危机**——迫在眉睫的危险
3. **身份反转**——原来 TA 是……
4. **伏笔引爆**——前面埋的线开始收
5. **两难抉择**——主角被迫做选择
6. **新威胁登场**——更强的敌人出现
7. **希望破灭**——刚燃起的希望被掐灭
8. **秘密泄露**——不该知道的人知道了
9. **倒计时开始**——时间压力突然出现
10. **视角切换钩**——另一处正在发生更危险的事
11. **承诺兑现**——兑现/失信承诺
12. **真相一角**——只露一角，不全揭开
13. **命运玩笑**——刚高兴就出事

### 对话规范

**每句对话必须有目的**（至少其一）：推动情节 / 揭示人物 / 制造冲突 / 传达信息 / 表达情感 / 制造悬念。

**无效对话**："你好""你好""吃了吗"——无信息无张力。

**好对话特征**：简短有锋芒、人物口吻不同、留白（不说破）、有潜台词。

### 人物塑造（矛盾创造深度）

**有效矛盾**（人物的发动机）：
- 雷厉风行的女警长，回家对亡夫照片说话
- 满口仁义的书生，暗中替人写休书
- 冷血杀手，每天给流浪猫带鱼
- 最不信命的人，抽屉藏护身符

**无效矛盾**：为矛盾而矛盾，与人物核心无关。

### 情节结构

每章 = 完整叙事单元：张力上升 → 冲突爆发 → 小收束 + 新钩子。

## 章末复盘（reflector，来自 v4 qc）

每章写完后深度复盘，输出结构化结果给真相文件：
1. **正文质量分析**（比审计更深）
2. **章节摘要增强**（补充真相文件 chapter_summaries）
3. **伏笔检测**（铺垫了哪些/推进了哪些/该回收哪些）
4. **更新真相文件**（JSON delta 方式，immutable 应用）

## 市场雷达（radar 具体方法，来自 v4）

**动笔前扫描市场**：
1. 查起点/番茄热榜当前题材分布
2. 记录：什么题材火 / 什么题材饱和 / 什么题材在上升
3. 判断：我的题材有市场吗？差异化在哪？
4. 目标读者画像：爽点偏好 / 阅读场景 / 弃书点
5. 结论写入 project brief（不盲写）

## 强制工作流（studio，来自 v3）

动笔后按顺序推进，不跳步：
`产品化 → 5层构建 → 真相文件 → 大纲 → 章节 → 免疫 → 审计 → 复盘 → 更新真相 → 读者仿真`

## 每章流程（合并所有版本）

1. 读真相文件 → 读大纲 → 读角色卡 → 查 SQLite 知识层（活着谁/悬伏笔/关系网）
2. COORD 定 preset（fast/standard/deep）→ 编辑部 8 角色：IDEA 出方案 → EXEC 写 → CHALLENGE/FACT/LOGIC 并行审 → ORCHE 定稿 → HUMAN 去 AI 味
3. 写前快照（可回滚）
4. 正则免疫（零成本）
5. 26 维审计 → 元认知失衡检测 → 按 FixHint 召回对应角色（不是全盘重写）
6. 针对性修改（只改问题维度）
7. 读者仿真（关键章节 / deep preset）
8. 更新真相文件（状态/伏笔/资源/摘要）+ ingest 到 SQLite 知识层
9. 章末钩（网文必须）

## 网文写作铁律

- **章末钩**：每章结尾留悬念
- **爽点密度**：每章 1-2 个情绪释放
- **金手指四维**：来源/限制/成长/代价
- **代入感**：主角视角为主，动机清晰
- **对话有差异**：不全员同声
- **防跑偏**：战力不崩/资源不无限/伏笔不丢

## 后台写作模式（delegate_task，来自 novel-forge-fusion）

长篇写作时用后台子 agent 模式：
1. 主 agent 前台陪用户聊（不阻塞对话）
2. 收集书上下文（设定/控制文件/上章结尾）
3. 构建详细写作提示（含质量要求）
4. `delegate_task` 派子 agent（toolsets: terminal+file）后台写章并保存
5. 写完汇报，主 agent 继续对话

**好处**：用户不用等每章生成，前台体验不断。
