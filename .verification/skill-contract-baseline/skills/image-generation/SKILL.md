# 图片生成

## 支持的图像模型

- **Agnes**：`agnes-image-2.1-flash`（fast，推荐）
- **阿里云百炼**：`wan2.7-image`（高质）
- **MiniMax-M3**：支持图文混合

## 用法

在对话中直接描述画面需求即可，例如：
> 帮我画一张水墨风格的黄河落日图，16:9

系统会自动调用图像模型生成，产物保存到 `生成物/图片/日期/` 目录，并在聊天界面展示。

## 提示词技巧

- 明确风格：水墨 / 水彩 / 3D / 写实 / 赛博朋克
- 明确比例：16:9（横图）/ 9:16（竖图）/ 1:1
- 明确主体与背景，避免歧义
