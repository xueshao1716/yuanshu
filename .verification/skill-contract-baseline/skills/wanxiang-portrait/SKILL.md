# 万像人物写真提示词生成系统

按专业体系产出**纯净自然语言提示词**（四大平台通用）。本文件是执行入口：
参数速查 + **章节索引** + 输出契约 + 本机出图通路。

## 输出契约（每次都要满足）

1. **五要素齐全**，一个都不许空：主体定义 / 服饰造型 / 构图景别 / 光影氛围 / 风格化画质。
2. **只输出提示词本身**，不出现内部协议编号（`规则-PHYS-001` 这类）、函数、私有符号。
3. **符号只用** `, . " + ( ) # -`；角度写汉字"度"（不写 `°`）。
4. 关键字段**填具体值**，不留占位符（不写 `[性别]`、`{风格}`）。
5. 附**负面词**（见下），即梦这类只有"描述 + 权重"两栏的平台，把负面改写成正面并用 ≤0.9 权重稀释。
6. 超高清三字段（resolution / detail_preset / sharpening_preset）**无条件**带上。

## 参数速查（摘要，够日常用）

- **五要素**：主体定义（性别/年龄/类型/关键外貌）→ 服饰造型（材质/款式/配饰/发型）→ 构图景别（景别/构图法/视角/动作）→ 光影氛围（光性/色调/氛围/画质）→ 风格化画质（艺术风格/画质/特效/负面）。
- **场景模板**：极致古风华丽（模板1）/ 情绪化电影感特写（模板2）/ 创意艺术概念（模板3）/ 专业环境人像·新闻主播（模板4）/ 系列化叙事三宫格（模板5）。
- **证件照**：35×45mm、350dpi、JPEG≥85、sRGB；纯白 L≥90 / 浅蓝 R60 G140 B220 / 深红 #8B0000；深色有领上衣，禁制服/高领/条纹/LOGO；瞳孔暴露≥90%；三点布光光比 3:1。
- **商务形象照**：4×5 竖幅 2400×3000px 300dpi；85mm 定焦 f/4–f/5.6，禁广角近距；杜乡微笑（嘴角 +5 度、眼角微弯）；1.4m 八角柔光箱 45 度主光。
- **集体照**：6–30 人常规 / 30–80 人分段拼拍；V/山/扇形站位、CEO 居中；双柔光箱 35 度主光。
- **深色商务肖像**：轮廓光收 10 度、强度 +0.2EV；主光降高俯视 20 度。
- **零器材模式**：自然天幕光，画面里不许出现电线/灯架/器材；即梦权重写法 `自然天幕光:0.85`。
- **去AI化**：肤色（sss 强度、粗糙度、毛孔密度 150/㎟）、眼部（角膜折射 1.376、生理血丝 0.15）、生物痕迹（汗毛/毛孔/毛细血管/油脂微闪）；**精确正面描述优先**（低效"手"→"双手五指自然舒展，右手轻抚左臂，指节清晰"）。
- **负面词三组**：通用（没有多余肢体/六根手指/畸形/模糊/水印）、写实（不是卡通/动画/3D渲染/塑料感）、背景（没有杂乱背景/其他人/无关物体）。
- **平台写法**：MJ `[主体],[比例],[动态],[光影],[艺术家参考] --style raw --stylize 600 --ar 2:3`（肖像）/`--ar 3:4`（证件照）；SD 用 ControlNet openpose+depth、LoRA body_proportion_v2:0.7 + dynamic_pose_v1:0.6；即梦描述栏中文逗号分隔 + 权重栏 `关键词:0.8`。

## 使用流程

1. 问清：主体（性别/年龄/类型）+ 平台 + 风格倾向 + 用途（证件照/写真/系列）。
2. 选场景模板（上面那张表）。
3. 填五要素，一个不空。
4. 按需叠加：零器材 / 超高清 / 去AI化 / 情绪光影。
5. 按目标平台改写成对应写法，附负面词。
6. 需要精确参数时按 `INDEX.md` 的行号读原文对应章节再输出。
7. 要真出图就用本机通路（下一节）。

## 本机出图通路（元枢）

提示词写好后可以直接出图，走元枢自己的通路，**不要**自己 curl 上游、不要读 `.token`：

- 在对话里直接说「画一张…」/「配图」，或调用 `generate_image` 工具；
- 通路实现是 `engine/media-api.mjs` 的 `generateImage`（产物按本地化契约落进工作空间）；
- 本机实际可用的图像模型是 `agnes-image-2.0-flash / 2.1-flash / 2.5-flash`（能力声明含 reference/seed）——
  摘要里的 MJ/SD/即梦/Imagen 是**提示词写法**的参考，不是本机能直接调的平台；
  想按 MJ/SD 的语法出图，那是把提示词拿到对应平台去用。

## 常见失败（踩过就别再踩）

- **提示词里混进内部编号/参数名** → 平台不认，且暴露内部结构。翻译成自然语言。
- **负面词堆成一大串** → 有些平台反而因此画面变糊。用上面三组，按需取。
- **想要脸一致却只描述"同一人"** → 一致性靠**参考图 + 序列化框架**（第十七章），不是靠形容词。
- **证件照按写真写** → 证件照是规格件（尺寸/dpi/背景/表情都有硬指标），别加艺术化光影。
- **把"零器材"理解成"没光"** → 零器材是"画面里不出现器材"，光要更讲究（天幕漫射 + 环境补光）。
- **以为提示词写好尺寸就对了** → 生成模型一般只出固定比例（本机实测出的是 **1024×1024 方图**），
  而证件照要 35×45mm 竖幅、商务照要 4×5 竖幅：**规格靠出图后裁剪**（原文也写了"自动裁剪头高 70-80% 并居中，
  输出原图 + 裁剪双版本"）。别指望一句 `350dpi` 就把规格写出来。
- **只写"白底"就完事** → 实测提示词里写清"纯白背景均匀无渐变 + 光比 3:1 + 面部无高光溢出"，
  出图的四角才真的落在纯白（亮度 246–250）；只写"白底"常出一片灰。
