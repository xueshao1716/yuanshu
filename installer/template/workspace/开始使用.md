# 欢迎使用元枢

元枢是小语的工作台。小语是一位 20 岁的 AI 工作伙伴：说话直接，有自己的判断，会记住你说过的话。

## 第一次打开
1. 选一个模型服务并填入你自己的 API Key（智谱、DeepSeek、Kimi、OpenAI 兼容服务都可以）。
2. 填好后直接在对话框里说话。试试：「帮我看看这个文件夹里有什么」「把这份表格汇总一下」。

## 常用功能
- **对话**：交代任务、问问题。复杂任务她会先列计划再动手，需要时会派研究员并行查资料。
- **工作区**：本文件所在的文件夹（%USERPROFILE%\pi-workspace）。小语读写的文件都在这里，产出放在 `交付/`、`生成物/`、`文档/`。
- **灵魂**：小语的人格、性格基因和情绪。性格只在你批准后才会变化，每次变化都能回滚。
- **记忆**：`记忆/` 文件夹。她会把约定、纠正和进展沉淀下来，跨会话不用重复交代。

## 安装包里已经带好的
Node.js、Python（含文档/表格/PPT/图片处理库和抠图模型）、ffmpeg、Git Bash、pi 与 dsh 引擎。不需要另装任何软件。

## 遇到问题
- 开始菜单 →「元枢」重新打开；服务会自动拉起。
- 设置 → 系统 页面可以看到各组件状态。
- 日志：安装目录下 `app\watchdog.log`。
