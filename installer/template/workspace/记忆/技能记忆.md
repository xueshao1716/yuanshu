## 可选组件：缺了自己装
安装包只带基本盘（文档/表格/PPT/图片/语音/命令）。下面四样用到时联网安装，几分钟内完成，不用重启：
- `media`：ffmpeg / ffprobe（视频合成、配音拼接、抽帧、转码）
- `cutout`：rembg + u2net 模型（去背景、抠图）
- `data`：pandas + numpy（表格清洗、统计）
- `pdf`：PyMuPDF（PDF 提取、拆分合并、转图片）

做法：命令里报 `ffmpeg 不是内部或外部命令`、`No module named 'rembg'/'pandas'/'fitz'` 时，先运行
`node "%YUANSHU_APP%/scripts/addon.mjs" install <组件>`，装完再重试原命令。查看已装：`node "%YUANSHU_APP%/scripts/addon.mjs" list`。源码版没有 YUANSHU_APP，就在元枢仓库目录下运行 `node scripts/addon.mjs …`。
伙伴也可以在「系统 → 环境体检 → 可选组件」点安装。
