# 复盘与挂账查证方法论

适用于周期性自我复盘（日/周）。核心原则：**复盘本身必须证据驱动**——不查证的复盘会复制错误（把已完成记成未完成、把一件事记成两件、基于错误记忆做二次判断）。

## 四段结构

1. **上次清单逐条销账**：每条给出「兑现情况 + 证据」（文件路径、验证数据、日志时间戳）。无证据 = 未兑现，不许凭印象打勾。
2. **昨日逐单复盘**：每单一段交代结果，重点核对交付闭环三要素，缺口单独标记。
3. **成长与反思**：提炼病根，不罗列事件（见下）。
4. **新行动清单**：fix 类必须带 due 日期，track 类标注持续跟踪条件；清单必须使用去重后的口径。

## 挂账查证三步（对账前必做）

1. **去重**：同一件事常以不同措辞挂多条（如「补两张欠图」与逐条「重跑XX」并存）。合并后按独立事件数重新编号，否则重复登记每轮滚雪球。
2. **已做未销**：翻当日记录核实是否已兑现——挂账时长 ≠ 未做，可能只是状态没更新。
3. **错误记忆回溯**：若某条挂账源自一次拒绝或一次「未交付」判断，必须回查原始请求原文，确认判断依据是否成立。教训案例：已交付的空姐视频记成未交付 → 基于错误记忆二次拒绝。

## 交付闭环三要素

每个交付必须同时有：**成品文件落盘 + 验证数据（尺寸/字节数）+ 交付路径**。记录断在任何一处都算未闭环，单独标记为缺口。典型断链形态：记录写到「落盘验证：」就没了——动作做了但没咽完最后一口气，缺口要单独立项补尾，不许留模糊。

## 病根级反思

- 把多个事件归因到同一病根（如「挂账重复登记」与「错误记忆二次拒绝」同根于「记账不查证」），每条反思必须区分「已修」与「待修」。
- 判断标准复盘：检查当天同类判断是否标准稳定——不因被反驳一次就松绑，也不因标签一刀切。判断错了就承认「是我记岔了」，随即修规则，不嘴硬。
- 产能反思要对照事实（如「当晚能迭代15版新单，5条老账零动作」），指出结构性原因（挂账区与即时会话抢产能），不许用「忙」糊弄。

## 坑

- 不要把「挂账天数」当作「未做天数」——先查证再计时。
- 已结清的旧账不复述，只留一句「账目干净」；复盘篇幅留给缺口和新模式。
- 复盘产出的新清单若不去重，重复条目会跨周期累积，破坏清单可信度。
