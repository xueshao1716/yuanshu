# 椒图 AI 提示词库（中文商用生图）

原始说明（完整保留）：椒图AI（jiaotu.ai）中文生图提示词库：57 条灵感库实战 prompt + 24 条首页示例，覆盖电商产品图/海报宣传/人像试衣/创意视觉/信息图/分镜动漫。含「中文电商生图配方」与参数化模板语法。当用户要画电商图、商品海报、白底精修、虚拟试衣、产品效果图、活动海报、知识卡片等中文商用生图时使用。

来源：jiaotu.ai 灵感库公开接口 `/api/v1/keyword/page` + `/api/v1/keyword/detail/{id}`
（2026-09-22 抓取，**无鉴权**，可随时用 `web-prompt-mining` 技能重新拉取更新）。
共 **57 条灵感库 prompt**（每条带推荐模型 / 画幅 / 参考图数 / 效果图）+ **24 条首页示例**。

**与 wanxiang-design 的区别**：万像是「从零构造」的方法论系统；本库是「已验证的真实语料」——
直接取用、替换变量即可，适合快速对齐商用中文生图的实际水准。两者可配合：本库出主体，万像调版式。

## 使用方法

1. 按需求查下表 → 读对应 `references/` 文件
2. **替换变量**：品牌名、产品名、场景、色调、比例 → 换成用户的
3. 若该条标注「需参考图 N 张」，**必须让用户先提供图**，否则出图会跑偏
4. 出图后按 `生成物/图片` 归档；需要中文字叠加时交给 `poster-typeset`（AI 不画字）

## 中文商用生图配方（从 57 条语料提炼）

### 通用结构（长 prompt，电商/海报类）
```
[任务句] 生成一张<用途>图，用来呈现<品牌/产品>
  ↓
[主体描写] 材质 + 造型 + 细节纹理（玻璃通透/绒毛感清晰/金属拉丝…）
  ↓
[场景与光线] 场景设定在<地点> + 光线类型（丁达尔光/侧逆光/柔光箱）+ 时间（清晨/雨后/黄昏）
  ↓
[构图与镜头] 平稳放置在<承载物> + 景别 + 虚化程度（深度虚化背景）
  ↓
[色调与质感] 冷暖对比 / 主色调 / 质感词（禅意、克制的奢华感、静谧的高级质感）
  ↓
[氛围收尾] 突出品牌<理念>，远景<元素>，整体视觉<评价>
  ↓
[负向约束] 不要变形 / 不要多余文字 / 保留原产品特征
```

### 一句话修图范式（首页 18 条验证）
**动词开头 + 单一目标，不堆形容词。**
- 消除类：`把照片上的<对象>给消除` / `请去除图片中所有水印内容`
- 替换类：`将照片的背景替换成<场景>` / `把照片上的<物A>替换成<物B>`
- 姿态类：`给我换个优美时尚的姿势` / `将图1中的角色替换为图2中的姿势`
- 视角类：`从鸟瞰视角生成这张图片` / `从特写视角生成这张图片`
- 跨图类：`让图片中的人穿上我上传的所有服装`（多图融合用「图1/图2」指代）
- 时间推演：`生成这张图片十年后场景的图片` / `生成图中两人物所生孩子6岁时的样子`

### 参数化模板语法（可复用到自建模板）
```
{argument name="product name" default="Apple Pods Pro 3"}
```
语义：给模型一个**具名字段 + 默认值**，用户填空即换主体。建批量模板时比纯 `{占位符}` 更稳——
模型知道这一格该填什么类型。

### 视频提示词范式（首页 6 条验证）
**场景句 → 主体描写 → 镜头运动 → 氛围/画质收尾**
例：`日出时分的雪山全景。<环境描写>。镜头缓缓掠过山巅，<光影变化>，背景配有空灵的大气配乐。`
镜头动词库：缓缓掠过 / 缓慢推近 / 定格 / 切换 / 伴随…翻滚机动 / 俯瞰

## 坑位

- **AI 不画字**：本库海报类 prompt 里若含中文标题诉求，出图后用 `poster-typeset` 叠字，
  直接让模型写中文大概率乱码
- **参考图依赖**：标「需参考图」的条目（共约 20 条）本质是**图生图**，纯文生图会失真
- **品牌名替换**：模板里的 `JiaoTu` / `蜜雪冰城` 等是示例，必须换成真实品牌，否则白出
- 语料是 2026-09 快照，平台会更新；需要最新时按 `web-prompt-mining` 重跑两个接口
