# 首页轮播示例语料（写死在前端）

> 来自 jiaotu.ai 首页组件反引号数组，接口里取不到。
> 特点：**极短指令**，验证「一句话修图」的写法范式——动词开头 + 单一目标，不堆形容词。

## 一句话修图指令（18 条）

- 去掉脸上所有的痘痘
- 让图片中的人穿上我上传的所有服装
- 让图片中的人和梅西一起踢足球
- 将图1中的角色替换为图2中的姿势
- 将沙发背后的墙面刷为浅红色
- 请去除图片中所有水印内容
- 制作图中物体的等距模型
- 给我换个优美时尚的姿势
- 从鸟瞰视角生成这张图片
- 从特写视角生成这张图片
- 将照片的背景替换成大海
- 把照片上的路人给消除
- 把照片上的果汁替换成可乐
- 让照片上的人物笑起来
- 生成这张图片十年后场景的图片
- 生成图中两人物所生孩子6岁时的样子
- 给照片上的人物换个发型
- 帮我设计一张"xx"主题的活动海报，地址在“xx”,时间是“xxx”

## 视频生成示例提示词（6 条）

> 范式：**场景句 → 主体描写 → 镜头运动 → 氛围/画质收尾**。可套用到任意视频模型。

1. 日出时分的雪山全景。从空中俯瞰连绵起伏的雪山山脉，山谷笼罩着晨雾，初升太阳将天空染成温柔的紫橙色。镜头缓缓掠过山巅，阳光为山顶镀上一层金边，背景配有空灵的大气配乐。

2. 独白表演场景。舞台中央聚光灯下站着一位青年男子，身穿旧式戏服，神情激动。他大声质问：“为何命运如此不公？”，声音在空旷剧院回荡。镜头缓慢推近他的面部，只见他眼含泪光，拳头紧握，整个身体因为情绪激动而微微颤抖。

3. 美食主播直播做菜。一个穿着厨师服的年轻女孩在明亮的厨房里，对着镜头微笑。她用中文说道：“大家好，欢迎来到我的厨房！今天我们要做糖醋鱼。” 背景整齐摆放着食材和厨具。女孩一边解说，一边娴熟地下锅烹饪，油滋滋作响，镜头时不时切换到食物的特写镜头。弹幕风格的评论在画面上飞过。

4. 真实电影级的空中战斗场景。从飞行员第一视角拍摄高速空战。我驾驶一架战斗机在云层间疾驰穿梭，紧追前方敌机并不断锁定发射导弹。座舱内部仪表盘闪烁警报，操纵杆剧烈震动。敌机呼啸着掠过视野前方，远处传来猛烈爆炸和浓烟。视角伴随战机翻滚机动，阳光时而晃眼，四周云层被尾流撕碎。整段视频画质4K超清，电影级光影和真实物理效果，每个镜头都让人肾上腺素飙升！

5. 第一人称视角，热门游戏《英雄联盟》的真人电影拍摄现场。镜头在片场游走，切换到不同的英雄角色：有的身穿夸张的铠甲正与导演交谈，有的在后台补妆调笑。工作人员来回穿梭调整灯光和布景，演员们全程用中文讨论着剧情。整个片场充满欢乐忙碌的气氛，偶尔还能看到CG特效预览画面在一旁的监视器上闪过。

6. 暮色下的都市街景。高楼林立的城市天际线被夕阳染成金红色，霓虹灯逐渐亮起。镜头定格在繁华街道的一角，川流不息的车灯拖出光轨，人群的剪影在地面拉长。远处天空乌云凝聚，隐约有雷电闪动，为城市增添一丝紧张氛围。
