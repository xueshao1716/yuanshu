# 抓拍感与表演

## 「未察觉抓拍」的三个机制

观众判断"这是摆拍还是抓拍"，靠的是**相机与人物之间的关系**。三种写法：

1. **相机像偶遇**：`相机仿佛偶然拍到她，在她发现镜头前有轻微延迟`
   —— 关键在那个"延迟"。镜头先拍到她，她后知后觉，这个时间差就是真实感。
2. **人物未察觉**：`没有察觉到镜头`、`人物未察觉的抓拍角度`
   —— 用于书店、公园这类沉浸场景。
3. **相机有物理支撑**：`相机低位靠在立柱上`、`近乎静止、有支撑固定`
   —— 手持有生命感，但"被放着"的相机更像偷拍。

**在表演栏点名哪几个镜头要抓拍感**（如"镜头 2、5 重点呈现人物没有发现镜头的真实抓拍感"），并在锁定栏复述。

## 克制表演的四条指令

> 克制自然的反应，不要夸张表演。

配套写法：

- 给**身体动作**而不是情绪词：「双手捧杯取暖」> 「她感到寒冷」
- 用**"轻轻/略微/短暂"**这类弱化副词：「轻轻一笑」「短暂抬头」「露出毫无防备的笑容」
- 允许**不完整的情绪**：「疲惫又满足的微笑」——单一情绪是演的，复合情绪是真的
- **不要给每个镜头情绪**：有的镜头就该是「松弛安静的神情」，什么都不表达

## B-roll 空镜（无对白镜头）的写法

无对白 ≠ 无内容。空镜要写三样东西：

| 要素 | 范例 |
|---|---|
| 一个持续的小动作 | 手指划过书架，抽出一本书翻了几页 |
| 一个环境音源 | 安静店内环境音、翻书声 |
| 一个光线描述 | 柔和窗光照在脸上，店内安静 |

并明确标注：`无对白`、`无台词，只收录呼吸声与笑声`。

**为什么必须显式写"无对白"**：不写，模型会自作主张给每个镜头配音配台词，全片变成连续解说。

## 生理细节清单（真实感的锚）

这三条性价比极高，写进表演栏几乎零成本：

- `所有特写镜头眼睛保留高光` —— 眼睛没高光立刻像 CG 人偶
- `镜头 1 可以看见呼出的白气` —— 体温 + 低温环境的物理证据（限冷天）
- `全程保留皮肤、织物真实质感` —— 防美颜塑料感

其他可挂：呼吸起伏、发丝被风吹动、指尖泛红、颈部细小动作。

## 对白策略

**总量**：30 秒片 → 1–2 句；60 秒片 → 3–4 句。超了必然口型崩坏。

**口语化铁律**：

| 口语 ✅ | 书面 ❌ |
|---|---|
| 好吧 —— 我们开始吧 | 让我们启程 |
| 谢谢，麻烦你啦 | 非常感谢您的帮助 |
| 敬这样的日子 | 为这美好的一天干杯 |
| 绝对是很棒的一天 | 这真是极美好的一天 |

**位置**：对白尽量放在**动作完成后**（转身之后、举杯之时），不要边走路边说——同步动作 + 口型是最容易翻车的组合。

**短促的感叹词最安全**：「谢谢」「好吧」，比整句稳。
