## 修复

1. 响应缓存不再存储失败状态，避免上游失败被下次请求伪装为 HTTP 200。
2. 缓存条目采用各自到期时间，并真正限制 maxKeys，淘汰最早写入条目。

5. 备用 ASR 按 SSE data 帧和 JSON 解码文本，保留转义字符，排除注释心跳；损坏帧/错误返回不作为成功识别。
