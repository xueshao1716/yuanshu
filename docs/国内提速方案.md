# 国内提速：可选方案与真实代价

> 2026-11-06 · 背景：`pi.myxinyu.xin` 走 Cloudflare Tunnel，国内访问 TTFB 1–3 秒。
> 先破除一个误会：**自己建 DNS 解析没用**——实测 DNS 只要 12ms，慢的是数据链路。

## 一、为什么不建议自建 DNS

```
DNS 解析      12ms     ← 已经是毫秒级，优化空间为零
TCP + TLS     700–2500ms ← 慢在这里
```

DNS 只负责“把域名翻译成 IP”。翻译再快，**数据还是要跨境走那一圈**。
自建权威 DNS（比如用阿里云云解析、DNSPod）能让解析更稳，但**不会让访问变快**。

> 唯一例外：如果你有**多个入口**（国内 ECS + 国外隧道），可以用「智能解析」按线路分流——
> 国内用户解析到 ECS，国外用户解析到 Cloudflare。这叫 **分线路解析**，是 DNS 唯一能帮上的地方。

## 二、国内可选的五条路

### ① 公网 IPv4 + 端口映射（最快，看运气）

部分地区可以找运营商申请公网 IPv4（家庭宽带默认是 NAT 后的内网 IP）。

- 拿到后：路由器端口映射 8787 → 电脑，域名 A 记录指向公网 IP
- 延迟：**10–30ms**，直连
- 代价：运营商不一定给；IP 会变（要 DDNS）
- 判断方法：路由器 WAN 口 IP 和 `ip.sb` 查到的公网 IP 是否一致

### ② 阿里云/腾讯云 ECS + frp（推荐，可控）

最低配 ECS（1核1G）约 **60–100 元/年**，学生机更便宜。

```
手机 → 你的域名 → ECS(公网IP) → frps ←→ frpc(家里) → 8787
```

- 延迟：**20–50ms**
- 备案：**用 80/443 必须备案**；用非标端口（如 8443）通常可以绕过
- 优点：完全自己掌控，可上 HTTPS（Let's Encrypt 免费）
- 缺点：要维护一台服务器

### ③ 国内商业内网穿透（最省事）

| 服务 | 价格 | 特点 |
|---|---|---|
| SakuraFrp | 免费档 + 几元/月 | 支持自定义域名 CNAME，节点多 |
| 花生壳 | 免费档 + 付费 | 老牌，稳定性一般 |
| 神卓互联 / LoLVPN | 十元级/月 | 面向 NAS 用户 |

- 延迟：**30–80ms**（看节点）
- 优点：**十分钟搞定**，不用买服务器
- 缺点：流量有限制，免费档不稳，要实名

### ④ IPv6 直连 + DDNS（免费，等条件）

运营商给公网 IPv6 + 路由器放行 8787 入站。

- 延迟：**10–30ms**（最快，且完全私有）
- 现在不满足：这台机器 `ipv6 global: 无`
- 一旦有了，我可以把 DDNS 脚本写好（阿里云云解析 API 更新 AAAA）

### ⑤ 国内 CDN / 边缘加速（不适合）

阿里云 CDN、腾讯云 EdgeOne 都需要**备案 + 源站是公网可达**。
你现在源站在家宽后面，CDN 回不了源，除非先解决 ①/②。

## 三、对比表

| 方案 | 延迟 | 一次性成本 | 月成本 | 难度 | 备案 |
|---|---|---|---|---|---|
| 公网 IPv4 直连 | 10–30ms | 0 | 0 | 中（找运营商） | 不需要 |
| 国内 ECS + frp | 20–50ms | 0 | 5–10 元 | 中 | 非标端口可免 |
| 商业穿透 | 30–80ms | 0 | 0–10 元 | **低** | 不需要 |
| IPv6 + DDNS | 10–30ms | 0 | 0 | 中 | 不需要 |
| Cloudflare Tunnel | 1000–3000ms | 0 | 0 | 低 | 不需要 |
| Tailscale | **5ms** | 0 | 0 | 低 | 不需要 |

## 四、我的建议

```
自己用（手机/平板）      → Tailscale，5ms，已经能用
要给朋友/客户打开        → 商业穿透（十几分钟搞定，几元/月）
要做成产品对外            → 国内 ECS + frp + 自己的域名
追求极致且愿意折腾        → 先查能不能拿到公网 IPv4，或等 IPv6
```

## 五、frp 最小配置（等你决定用 ECS 时用）

**ECS 上（frps.ini）**

```ini
[common]
bind_port = 7000
token = 换成你的长随机串
vhost_https_port = 8443
```

**家里（frpc.ini）**

```ini
[common]
server_addr = <ECS 公网IP>
server_port = 7000
token = 同上

[yuanshu]
type = https
local_ip = 127.0.0.1
local_port = 8787
custom_domains = pi.myxinyu.xin
```

然后把 `pi.myxinyu.xin` 的 A 记录指向 ECS 公网 IP。
（HTTPS 证书在 ECS 上用 certbot 申请，或用 frp 的 `plugin = https2http`）

## 六、分线路解析（将来可做）

如果同时有国内 ECS 和国外 Cloudflare：

```
阿里云云解析：
  pi.myxinyu.xin   默认   → ECS 公网 IP
  pi.myxinyu.xin   境外   → Cloudflare 的 CNAME
```

这样国内直连 ECS（20ms），国外走 Cloudflare。
