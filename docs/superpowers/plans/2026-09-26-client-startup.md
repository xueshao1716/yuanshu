# 元枢独立启动与守护修复

目标：第7项第一批完成 Windows 桌面在后台未运行时的安全启动。已有网页、手机入口和其他未提交界面改动保持原样。

## 设计边界

- 本地内置启动页不依赖8787；正常实例直接进入，失败可重试、可关闭。
- 原生固定命令只请求已注册的 `yuanshu-watchdog` 任务，不接受路径、端口、命令参数，不自动提权。任务不存在/权限不足直接说明原因。
- 守护任务使用绝对 Node 路径、带引号脚本路径；启动和登录触发，五分钟无限期兜底；重复实例忽略。
- 守护健康检查验证 HTTP JSON `ok:true`；端口被其他服务占用时报告异常但不杀进程。
- 启动流程单飞；自己拉起且仍活着的子进程不重复拉起；保留现有崩溃归因规则。
- 不提供公网启动API。手机/网页独立且鉴权的恢复控制面属后续批次；不能将本次称第7项全部完成。
