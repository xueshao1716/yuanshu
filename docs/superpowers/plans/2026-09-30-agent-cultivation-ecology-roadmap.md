**Tech Stack:** Node.js ESM、node:test、现有文件锁与原子写入、元枢任务运行存储、React/TypeScript/SWR、隔离验证脚本。

## 阶段 2：真实设计与用户控制

进展：内部身份授权接口、设计/生命周期、持久对账及分页投影已经实现；生产写入仍关闭。执行计划见 `2026-09-30-agent-cultivation-controls.md`，实际实据与未完成项见 `2026-09-30-agent-cultivation-controls-results.md`。不能把合成可信来源测试等同于真实身份出口通过。

依赖阶段 1。形成 `2026-09-30-agent-cultivation-controls.md` 执行计划时必须解决：

1. 由服务认证上下文产生 actor；设计作者需绑定实际母体 run/session 和 workspace。用户策略及控制使用可信人类控制渠道；共享 bearer token 只证明登录，不足以区分用户与模型。复核 `engine/maintenance-approval.mjs`，不足时增加明确的、短期且不可由模型上下文取得的控制凭据。认证未闭合前控制端点保持关闭。
2. 小语提交草稿、理由、观察/恢复方法、外貌/服装/声音；用户可以修订，但作者如实记录。保护项不是普通设计字段，拒绝自动采用并引用现有提案 ID。
3. 一个工作区控制文件中原子保存政策修订、设计版本、个体登记及初始状态待同步意图。孩子文件初始化采用幂等意图 ID；崩溃后对账完成，不向 UI 宣称跨文件原子性。
4. 用户暂停/归档先持久化派发禁令，恢复重新校验当前政策。取消要等宿主确认；控制请求有幂等键、版本检查和不可由 API 删除的审计。修正写新设计版本；回退只指向仍有效且获当前策略允许的历史配置，不删除后来事件，也不声称撤销外部副作用。
5. 列表上限 50、稳定游标、当前 workspace 过滤。阶段 1 整文件基础读取不直接用作高频列表扫描：增加进程内按文件版本失效的只读投影，受控写入更新索引，损坏时拒绝服务而不是展示旧成功。

出口测试：真实身份来源与伪造字段；过期/跨工作区/跨个体；同请求重复登记；双进程并发；一次写入后故障再恢复；暂停不被刷新或重启解除；配置回退保留历史且拒绝恢复已撤销权限；审计不能覆盖；只读请求零模型调用。

## 阶段 3：有界任务与共同资源约束

依赖阶段 2。形成 `2026-09-30-agent-cultivation-execution.md` 时必须解决：

1. 现有 `engine/knowledge-budget.mjs` 会把 policy revision 与知识策略比对，账本属于 `记忆/知识/`。不能给它传培养策略就声称共用预算。
2. 建立受锁保护的共同日账与 admission：owner 区分 knowledge/cultivation；分别校验自身策略，同时扣减共同总额和并发。保留既有知识预算记录，迁移前先做备份/校验；历史 unknown 额度不得释放。迁移失败时培养关闭，不影响原知识账本的可读性。
3. 预留先于请求，结算后于可验证结果。此阶段扩展已版本化策略的调度窗口、时区和单次超时；未配置窗口保持不派发，禁止依赖机器默认时区。并发策略修改/撤销需在发出前再次校验；无可靠费用上限拒绝付费请求。前台聊天/语音忙时拒绝新后台派发，不能从第二队列绕过。
4. 复用 `engine/subagent.mjs` 的有界任务能力和任务追踪，不继承任意文件、网络、媒体或 computer-use 权限。当前文本任务契约不支持的能力明确拒绝。真实模型费用另行授权。
5. 每次派发保存幂等键、政策/设计版本、宿主 run ID、租约和取消请求。重启核对宿主；结果未知保留待核对，不照抄知识任务的过期租约自动重排逻辑。
6. 持久个体不创建常驻进程；禁止递归养育。每次执行有超时、输出上限、取消和清理；课程或外部事件才创建新任务，不以自己的回流事件无限触发。

出口测试：知识与培养共同抢最后额度；跨日/重启/时钟倒退；未知结算；策略撤销竞争；前台优先；执行前/后崩溃；宿主取消失败；网络副作用未知不重放；不递归。全部先用合成提供者。

## 阶段 4：证据回流与 aibody 观察

依赖阶段 3。形成 `2026-09-30-agent-cultivation-learning.md` 时必须解决：

1. 经验存权威源事件引用、actor/source kind、run/session、内容哈希、祖先链及反例。不存在或不可读来源标失效，不能补造。
2. 一个祖先来源的多次复述只算同源；模型自评、工具结果和用户真实验收分开。孩子及模型评审不写入母体的用户 gene observations/emotion 输入。
3. 经验候选与现有知识队列采用幂等 outbox/reconcile；知识正文仍由知识系统持有。母体/孩子分别有采用、修订、舍弃和退役记录。
4. 纯事实走验证；方法/状态调整走有预设判据、范围、期限和退出条件的试验。未验证候选不注入为事实，试验身份必须可见。
5. 数据范围及派生敏感性通过确定性标记/引用检查；无法证明可共享则不发送，不能仅凭模型“已脱敏”放行。撤销后停后续使用并标待核对，不宣称已撤回发送给外部模型的内容。
6. 土壤观察只投影已有事实：缺证据显示未观察；不合成健康总分；稳定倾向、临时表达、知识方法分开。情感设计由小语提交，不以服从、持续积极或诱导痛苦为指标。

出口测试：循环引用/重复祖先；伪造人类验收；来源被删除；撤销派生权限；部分知识提交后重试；反例导致退役；保护项仍要求现有真实证据及人工批准；母体 baseline 保持不变。

3. 查看不派任务；页签隐藏/卸载取消轮询及订阅，恢复时限流刷新。错误有原因和可操作的恢复路径；禁止把待核对渲染成成功或已停止。
