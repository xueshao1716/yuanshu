# 手机回复朗读接入阶跃

## 原因与边界

2.116.28 的回复朗读只使用 Web Speech API。部分手机 WebView 没有该能力，UI 因此禁用自动朗读；模型库的 TTS 配置从未接到回复朗读按钮。

2.116.29 新增云端 MP3 播放适配器，保留原设备适配器。不改原生壳、麦克风权限或主聊天模型；无需为该网页功能重打 APK。自动朗读每次打开页面仍默认关闭。

## 实现

- 受原有访问令牌保护的 `GET /api/tts/capabilities` 和 `POST /api/tts`。
- 从模型库寻找 `stepaudio-2.5-tts`，凭据只在服务器取用；请求体不能覆盖供应商、端点、模型、密钥。返回实际模型/供应商头。
- 2.116.29 初次接入沿用 `cixingnansheng`；2.116.30 按用户要求改为官方「气质温婉」女声 `elegantgentle-female`，能力接口同步报告音色及名称。这是预置音色，不是小语专属声音克隆。
- 云端正文外发和计费提示；用户可选设备/云端，设备不支持时预选云端但不自动播放。
- 只朗读清洗后的回复正文；约 600–1000 UTF-16 单元分段、串行按需合成。服务端单段最多 2000，最多 2 个并发、60 秒上游超时；停止取消请求并释放 Blob URL。
- 浏览器拒绝自动播放时保留准备好的音频，显示继续按钮，不重复合成。切换会话和录音调用原有统一停止接口。
- 上游失败明确显示错误，无静默跨供应商降级，不修改媒体创作工具的既有 TTS 路由。

## 手机使用

刷新或重新进入会话，在输入区附近选择“阶跃云端”，点击某条已完成回复下的“朗读”。需要新回复自动播报时再开启“自动朗读”。若显示“音频已就绪”，点击“继续”允许播放。

## 女声音色与通话边界（2026-09-27）

- 官方音色依据：https://platform.stepfun.com/docs/zh/guides/developer/tts.md 。其中标明 `stepaudio-2.5-tts` 支持气质温婉、温柔女声、温柔熟女、亲和女声、甜美女声、知性姐姐等；目录支持不等于本账户逐个实测。
- 气质温婉在现有 Step Plan 通道真实合成成功：HTTP 200、117034 字节、ID3 MP3，约 3 秒返回。样例只使用新写的测试句，不外发会话历史。音频保存在 `tmp/xiaoyu-gentle-female.mp3`，最终听感由用户试听判断。
- 目前是手动录音→ASR→输入框，聊天完成后可 TTS 朗读；不是持续通话。本轮只改默认音色，不暗中开启麦克风或更换主聊天模型。
- 建议下一阶段做保留元枢会话/人格/工具的轮流式连续语音：用户明确开始/挂断，静音检测、自动提交、答完继续听，静音/取消、切会话停止、错误可恢复。播放时暂停监听以避免回声自问自答。
- 可打断的全双工另行验证实时 ASR/音频传输、回声消除、服务器取消和模型权限；不能把普通 TTS 接口称为全双工能力，也不承诺手机锁屏或后台持续录音。
