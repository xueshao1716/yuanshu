# 灵魂培养中心：已批准设计与实施计划

用户已确认独立培养中心方案，并授权无冲突并入元枢。实现遵循 existing-world / Operate 模式，不重设计其它页面。

## 设计契约

- 单入口 `#/soul`，桌面更多、手机更多、系统页可达。总览与九个培养分区，左侧导航、右侧工作区，手机选择器。
- 分区：身份与表达、性格基因、情绪与节律、记忆与关系、学习与技能、aibody 母体、天团协作、声音与形象、审批与回退。
- 使用元枢既有字号、主题变量与控件；沿用已批准草图的安静、明确、少装饰方向。对事实、配置、证据、待建能力做明确区分。
- 所有展示来自现有唯一数据源。不能复制人格、基因、语音或形象配置；不能伪造培养分数和运行健康。
- 人格编辑先查看差异，再关联有效会话、本机人工确认；读取失败不可用默认值覆盖；比较读取版本以阻止旧页面覆盖新设置；留备份、审计并支持安全回退。
- 基因基线仅提案/审批/回滚，沿用现有证据门与本机确认，不改自动审批策略。
- 记忆、学习、天团使用原有管理入口和真实运行记录；不为开关好看发明不存在的运行策略。
- 不恢复外部系统自动同步；不更改任何真实人格来测试功能。
