范围：按已确认的第四项 Q4 实现显式记录、查询、撤回；不运行实验、不自动采纳、不修改人格/技能/授权、不新增模型调用或 UI。

1. 在隔离 worktree 跑基线验证；保留主目录全部未提交内容。
2. 测试先行：真实运行绑定工作空间及会话；合成样本明确隔离；原做法和最多两个替代做法保存版本、来源、产物指纹、失败、已有验收、实际模型/引擎及已知消耗。未知保留 null。
3. 实现 `behavior-experiment-contract.mjs`、`behavior-experiment-source.mjs`、`behavior-experiments.mjs`：有界读取、跨进程锁、原子落盘、幂等写入、冲突拒绝、撤回历史、读时失效检查。
4. 实现 `behavior-experiment-routes.mjs`，挂到现有鉴权路由；生产入口不允许合成样本冒充真实任务，不接聊天收尾和后台周期。

6. 跑定向测试和隔离全量验证（测试、类型检查、非线上构建）；后端变更无 UI 截图项。审阅差异，更新设计/跟进文档和验收证据后窄提交。

结果只允许 `comparable` / `incomplete` / `failed` / `stale` / `revoked`；comparable 仅表示比较材料齐备，不代表更优。`adoptionEligible` 和 `improvementProven` 恒 false。

真实样本必须来自已存在、同工作空间及同会话的授权任务；没有合法完整对照时保留真实任务验收缺口，禁止补跑付费任务凑数。首期不重启、不打包、不远端推送。
