# 真人公仔与情绪潮汐联动设计

日期：2026-09-26
状态：方向已认可；书面规格待用户复核，尚未实施。

## 1. 已确认的方向和范围

采用“同一真人形象的动作素材 + 真实运行状态 + 模型行为决策”。用户确认联动右上角情绪潮汐。
沿用现有成年虚拟女性真人母图，移除公仔全部卡通皮肤入口，迁移旧皮肤偏好。
本次升级现有网页内悬浮公仔，不新建独立 Windows 透明窗口，不增加电脑权限。
本规格取代旧预览方案中“保留卡通选择/默认卡通”的要求，但不改写旧验收记录。

过程清单：上下文核对、方案比较、方向确认已完成；本文完成后自审；书面复核通过后进入实施计划和 TDD。

## 2. 当前代码事实

- `XiaoyuWidget.tsx` 的真人模式只有同一张图片，忙碌/点击改变状态但不切换真人动作；点击有固定短暂问候状态。
- `xiaoyu/useWidgetStatus.ts` 轮询全局任务列表，不足以证明当前会话正在做什么。
- `useXiaoyuEmotion.ts` 使用共享 `emotion-live` 缓存，读取不带 session 的 `/api/emotion`；顶栏和工作台共用此来源。
- `engine/emotion.mjs` 的 `getLatestSnapshot()` 实际选择最近交谈会话的快照，不是所有会话的情绪融合。
- `snapshotOf()` 会清空原状态 tags；多处展示读取存在相互消耗标签的风险。
- 聊天 SSE 的 emotion 事件直接覆盖共享缓存，当前缺少用于全局更新比较的来源和顺序封装。
- 当前缺失数据会回退“专注”，数值展示可能回退零；新联动不能把这些默认值当作真实观测。

## 3. 两层状态，避免混用会话

**共同心情层**：维持目前全局“最近对话情绪”的产品语义。潮汐、展开面板、公仔共用同一快照，明确标为“全局最近对话情绪”。不冒充当前会话情绪，不输出来源会话正文。

**当前行为层**：工作、阅读、回应内容只读取当前选中会话的运行证据和用户互动。全局其他会话仅提供活动数量，不提供标题、路径或正文。离开会话页时不继承上一个会话的互动语境。

全局仍有任务时可显示“后台有任务”的工作姿态；详情只显示数量和“其他会话”，不能说成正在处理当前会话的内容。全部执行事实未知时不显示睡眠或断言闲置。

## 4. 同源情绪读取协议

增加不消耗状态的展示读取路径；保留现有任务侧语义，先核对旧调用方，禁止直接改掉全部 tags 消费行为。
展示快照包含 state、scope、observedAt、servedAt、sourceKind、revision、serverEpoch、status。

- scope 固定 global-latest；sourceKind 区分近期对话、历史残留、无观测。
- revision 在情绪内容/来源改变时增长，轮询本身不增长；serverEpoch 区分重启。
- observedAt 是真实状态更新时间，不能用请求时间伪造；servedAt 用于连接新鲜度。
- status 区分 observed、historical、unavailable；时间缺失不编造。
- 不向公仔传输全局快照中的原始 residue、私有片段、文件路径或来源会话正文，仅用数值和经白名单处理的情绪标签。
- SSE 使用同一封装；未升级的旧事件只触发重新验证，不能无版本覆盖全局状态。迟到 revision 不覆盖新值；epoch 变化重新取得权威快照。
- 保持共享轮询，默认 20 秒；超过 60 秒无法确认连接标记陈旧。历史情绪本身可以保留，但明确不是刚发生的新观测。
- 缺数据时统一显示“暂无情绪观测/情绪暂不可用”，数值为缺失符号，不声称专注。

潮汐的呼吸、光感与公仔的光晕、动作强弱可用相同 VAD 映射。颜色变化不改变衣服、脸或人物身份；情绪不能覆盖任务事实。动画不反向写入情绪。

## 5. 真人状态及事实约束

| 状态 | 准入依据 | 展现 |
| --- | --- | --- |
| 工作 | 当前会话真实运行；或明确标注的全局后台运行 | 桌前专注、记录；状态来源可查看 |
| 阅读 | 当前 run 正在执行可识别的文档读取工具，且有开始事件 | 持书/阅读姿态；工具结束即撤销“正在读” |
| 休息/睡眠 | 运行状态新鲜，确认无任务；用户要求或模型从空闲状态选择 | 闭眼休息；说明是呈现状态，不声称生理睡眠 |
| 发呆 | 确认空闲，模型选择 | 放松、望向一侧；不宣称后台思考/学习 |
| 倾听/回应 | 当前会话的用户互动或回复事件 | 面向用户、轻微手势；文字由模型结合上下文生成 |
| 中性待机 | 模型不可用、状态未知、素材失败或决策过期 | 已有真人母图；必要时显示简短事实状态 |

状态约束优先级：事实不可用提示 > 真实活动约束 > 用户勿扰/休息偏好 > 有效模型决定 > 中性待机。
工作中仍可短暂回应点击，但必须保留任务状态标识，不能标成空闲或睡眠。
勿扰只控制公仔主动冒泡，不静音任务错误/审批，不停止任务。休息请求也不停止任务，有任务时说明仍在执行。
不能只靠固定时间、随机数或几个模板把公仔伪装成“自主智能”。

## 6. 模型行为协议和资源边界

增加独立只读决策服务，不复用主任务的有副作用工具循环，不获得文件写入、命令、浏览器或电脑权限。
输入包含：当前会话 ID、上下文代次、运行证据摘要/证据 ID、脱敏全局情绪快照、近期本会话对话片段、显式互动、勿扰偏好。
只取最近 6 条本会话消息并限制总长度 6000 字符；证据摘要不带工具原始结果。记录此上限，不能默默读取其他会话补上下文。
模型走现有统一模型适配层，记录实际文本模型/引擎；自动候选降级必须显示实际来源，不能假称仍用首选。

返回结构：decisionId、sessionId、contextEpoch、basisRevision、action、expression、utterance、reason、evidenceIds、durationMs、shouldInterrupt、expiresAt、actualModel、decisionSource。
action/expression 用白名单；utterance 为纯文本最多 80 字；reason 为可展示的短依据，不索要或显示内部思考链；durationMs 限 5–60 秒。
模型没有权限指定任意图片 URL、HTML、脚本或新工具调用。素材只能由受控 manifest 映射。
服务端验证会话/版本/证据/事实约束和输出模式；失败返回显式 unavailable/invalid，而非生成假模型对白。

事件驱动：用户互动、任务开始/结束、阅读开始/结束、情绪实质变化、切换会话时评估。
安全状态变更立即采用事实，不等模型；事件合并 500ms。自动模型决策每会话至少间隔 30 秒、每小时最多 20 次。
显式互动独立限频每会话 2 秒、每小时最多 60 次；多标签共用服务端额度，同时最多 1 个请求，会话请求合并，服务整体最多 2 个决策请求。
单次超时 12 秒，不自动无限重试；退避 60 秒，可用下一个显式互动重试。返回 actualModel 和失败原因，不能因此给正常主模型记不可用。
页面隐藏不发起自动决策；恢复时重新取事实，不重放旧气泡。响应到达后复核最新证据，切会话/旧 run/过期响应直接丢弃。
没有互动和状态变化时不持续花费模型额度；过期自动回中性真人，事实状态标识仍更新。

## 7. 互动和记忆

支持点击/轻触、输入一句话、询问“忙什么”、勿扰、恢复互动、请求休息。
点击是一个有上下文的事件，不强制每次挥手/固定台词；也允许模型选择安静回应。
自由文字默认仅作为公仔互动，不启动任务；若用户要执行工作，提供明确的“带到当前会话”入口，正常聊天发送流程仍需用户动作。
勿扰按账号/工作空间持久化，同步多端；当前互动历史按会话隔离，空会话不读取历史。
仅记录结构化互动、采用/拒绝的决策和依据 ID，默认保留最近 7 天且总量不超过 1000 条，避免无限增长；不存模型完整提示词和主会话正文副本。
情绪变化复用既有事件评估路径；同一 interactionId 幂等处理，不让同一点击分别经公仔和聊天重复增加情绪。
不自动写人格/长期记忆，不改变既有人工治理；不使用“你不来我就难过”等依赖施压文案。

## 8. 视觉与迁移

首批素材：中性、工作、阅读、休息、发呆、倾听、回应，共 7 种。
以现有真人图片为一致性参考，保持成年形象、面容、长发与衣着一致；每种动作真实区分，不拿同图加文字充数。
允许道具与坐姿改变；不采用卡通部件、布偶关节、左右翻转脸部或随机换人。
交付 manifest 记录动作、文件、尺寸、透明边缘验收结果及生成来源；生成未成功的状态回母图，必须标记素材缺失，不算交付完成。
静态真实动作图 + 克制的呼吸/视线氛围/交叉淡入淡出，不宣称实时真人视频。动作自然度超出静帧范围的实时口型和骨骼驱动不在本轮。
保留拖拽位置、缩放、隐藏、复位、更新检查；旧皮肤偏好统一映射 portrait，去掉玩偶工坊入口，不删除 unrelated 图片或别处品牌标识。
减少动态偏好时停呼吸/漂移动画；保留键盘焦点、触摸可用按钮、可关闭气泡，不遮挡停止和审批控件。
右上角情绪潮汐原有造型保留；展开面板展示同一真人状态与情绪依据，不再出现旧卡通公仔。全站其他插画不属本轮。

## 9. 模块划分与验收

后端分为展示快照适配、运行事实汇总、只读模型决定/校验、偏好与有界记录；前端分为共享快照订阅、行为控制、真人素材呈现和互动面板。沿用已有鉴权与工作空间隔离。
新增接口限定在公仔命名空间并走现有鉴权；读取接口无副作用，决策/偏好更新使用 POST。不得公开内部模型凭据或任意访问其他会话。

先写失败测试再实现，覆盖：

1. 旧卡通偏好迁移、唯一真人入口、素材缺失降级。
2. 展示读取不消耗 tags；两消费者顺序读取和 SSE/轮询乱序时快照一致。
3. 全局最近情绪与本会话行为的来源标注；不同会话正文/产物不进入互动提示。
4. 工作覆盖睡眠、阅读必须有当前工具证据、执行事实未知不冒充空闲。
5. 决策过期、切会话、重启 epoch、模型异常、非法动作和越权指令。
6. 勿扰持久化、限频/并发/隐藏页节流、事件幂等和记录上限。
7. 桌面及手机的拖动/触控/键盘/减少动画；不遮挡主任务控制。
8. 用真实已配置模型验证“工作时问忙什么→完成→休息→新任务立即唤回工作”，并保存实际模型和事件依据；不能仅用冻结用例算完成。
9. 七种真人图逐一校验文件解码/尺寸，目视验收同脸、手部、衣着、道具、透明边缘；自动解码不等于目视通过。

全量用 `npm run verify` 隔离测试/类型检查/非线上构建，前端变更补专项静态检测与浏览器验收。
模型或素材通道不可用时如实列出未验收项；不得把摆拍状态描述为已完成真实模型驱动。
源码完成后才协调部署，检查活跃任务并保留其他未提交工作。后端需要重启，不能单独上线依赖新协议的前端。
此书面设计提交不触发重启、打包、双推；纯网页变更无需重打原生壳。

## 10. 自审结论

已明确：共同全局心情不等于共享会话正文；互动不等于执行授权；读取不能消耗情绪；模型只决定表现不编造运行事实；睡眠是休息呈现不是生理状态。
范围聚焦真人公仔及既有情绪潮汐联动，未扩展电脑控制、自主长期工作或全站重设计。素材和真实模型验证均为交付门槛，不预先记为通过。
