# 参数生效与同步朗读

用户已批准顺序：补齐参数按钮 → 统一音色 → 改进流式朗读。

- Pi 主通道每轮包装原有请求 payload hook，透传有效 temperature/top_p；保留扩展 hook，结束或异常后恢复，不串会话。不强塞不支持采样的推理协议。
- 参数面板区分模型默认与本机自定义；恢复默认表示不覆盖上游，不假装默认 0.7/0.95 已发送。
- 云端朗读与通话共享邻家姐姐音色 ID；不擅自覆盖设备声音选择，也不启动麦克风。
- 自动朗读监听本轮新增正文，短句生成后立即提交。代码与链接过滤、幂等快照、停止后不重启；结束仅冲刷尾句，不重读整条。
- 短句通过已鉴权 HTTP 请求连接官方流式 TTS，音频增量下行并由 AudioContext 连续排程；播放和后续合成重叠，有界预取，取消即断开，保留整段高音质手动朗读。
- 不故意拖慢文字；不能保证逐字零延迟。流式 TTS 有音质/时延取舍，官方协议已核对。

验证：先红后绿的采样适配、增量切句、播放队列、取消/暂停、协议/断连测试；界面契约及浏览器测试；隔离全量验证与类型、构建检查。无额外模型调用或收费试听。
