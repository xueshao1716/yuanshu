# 网站工坊：从想法直接生成

用户已批准实施。此方案接续 2026-09-24 网站工坊，不重做编辑底座，不发送微信通知。

- 默认只需输入想法，名称可选；选择文本模型后立即创建后台任务。模板收进可选参考，不强制选择，不作为新创作必须保留的页面。
- 新创作先生成设计方向与区块计划，再按区块生成 HTML/CSS，最后校验、组装成候选版本。已编辑作品的整页优化和选区修改保留原有边界；另有明确的重新设计模式。
- 修复 directChat 的 8192 硬上限，尊重请求预算、模型声明及安全上限。三种协议统一报告结束原因、截断状态、实际模型与预算；工坊显式保留部分正文，推理内容不充作网页。
- 截断最多恢复一次（续写并保留原片段），结构校验最多修正一次；每次调用和整项任务都有超时及取消边界。复杂页面用分区任务避免一次输出整页。正常网页编辑遇到反复截断不无限重试、不自动换模型。
- 运行记录保存部分响应、区块检查点和请求信息；失败/服务中断后可显式继续，已完成区块不重跑。不得将不完整正文作为成功版本。后台任务不随手机锁屏停止。
- 打开新作品立即显示执行过程，手机也能直接看到；展示实际阶段而非虚构进度。结果经用户采用后才替换画布。现有作品、草稿、历史版本保持不变。
- 不扩展任意 JS/React 执行能力；继续使用现有安全 HTML/CSS 验证、隔离预览和受控分享。

验收使用临时目录、可控 HTTP 模型和真实浏览器。运行类型检查、全量测试、构建和界面扫描；版本更新后重启验收，按仓库约定双推。不宣称网页更新等同于重打安装包。
