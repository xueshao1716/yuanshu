# 元枢手机实时通话接入（试听版）

日期：2026-09-28
状态：接入方向已获用户认可；本文待用户审阅，尚未实施、部署或通过手机验收。

## 目标与本轮边界

用户使用手机麦克风与扬声器，在元枢现有聊天页面与小语双向实时交谈；电脑仅承载服务。入口不能跳转到 `127.0.0.1:8788`，不能以独立测试会话冒充当前聊天接入。

本轮先交付试听版：开始、静音、打断、挂断、错误提示及通话内转写。服务端读取当前会话有限上下文。不开启任务派发、历史跨会话搜索、电脑操作或文件工具，也不宣称完成 2026-09-27 设计中的多任务协调。现有独立实验室保留原样，不作为手机入口。

## 方案选择

- 采用：在元枢现有聊天页面加入通话面板，通过同一 HTTPS 域名及服务端语音桥通信，复用登录保护与当前会话身份。
- 不采用：新增独立公开实验室域名。它需要独立鉴权，仍不能实现当前聊天体验。
- 不采用：把本机实验室端口直接转发到公网。其 bootstrap 依赖本机访问边界，不能作为公网认证。

## 交互与会话绑定

1. 在现有聊天输入区提供“实时通话 · 试听”入口，适配窄屏，挂断按钮始终可见。没有会话时先通过现有机制创建会话。
2. 开始前说明：声音与有限当前聊天内容发送给阶跃，消耗现有通道额度；用户明确点击后才申请麦克风权限。页面载入不得申请权限或连接付费模型。
3. 通话绑定发起时的真实会话 ID。切换会话、退出登录、隐藏或关闭页面时结束采音、播放和供应商连接，防止后台收音或上下文串用。
4. 与现有语音转文字录音互斥；通话前停止自动朗读，通话期间禁用可能争抢音频的入口，不修改文字主模型。
5. 通话面板展示当前通话的转写及状态。试听版转写仅保留于通话面板，不伪装成已持久化的主聊天消息；刷新即不再保留。此限制在面板明确提示。

## 服务端与安全

- 新增独立语音模块，以最小改动接入主服务，不把实验室任务运行器及临时工作空间并入线上。
- 复用现有登录令牌校验；服务端验证会话存在、可访问后，从该会话读取最近最多 12 条用户/助手文本消息，总上下文不超过 8,000 字符。不接受客户端提供任意会话正文、文件路径或工具定义。
- 使用单独的短时、单次连接票据：由已认证请求签发，绑定会话与登录身份，60 秒内有效；浏览器通过 WebSocket 首包发送。票据、主令牌与供应商密钥均不得放在 URL、日志或错误正文。
- WebSocket 校验明确配置的允许来源；不凭任意 Host 或转发头自动扩大来源范围。错误来源、无效或重放票据、首包认证超时以及失效会话均拒绝，认证成功之前不连接供应商。
- 对待认证连接、票据签发速率及数量设置上限。每个登录实例只允许一个已认证活动通话，单次最多 25 分钟。保留帧大小、消息速率、发送队列与响应数量限制，拒绝二进制及未知事件。
- 供应商密钥仅由服务端读取现有凭据配置。实时模型只做听说，没有工具调用权限；不得声称受理或完成电脑任务。
- 默认不存原始音频。错误、断线、挂断及页面离开均释放音频设备、播放器、定时器和供应商连接；不无限重连、不静默改用其他模型。

## 前端复用与移动端处理

复用经测试的实验室采音、PCM 重采样、播放队列和打断处理，提取到主前端独立模块。音频 worklet 使用构建生成的资源地址，不沿用实验室根路径假设。

按钮启动路径保留用户手势以初始化音频；权限拒绝、不支持的浏览器、不安全连接、网络超时或后台挂起均显示明确原因，不能在实际已停采音时仍显示“正在聆听”。不承诺锁屏、后台持续通话。

## 外网入口与部署边界

手机使用既有 `https://pi.myxinyu.xin/`，不另开公网端口，不移除现有登录保护，不要求用户用 HTTP 登录。

2026-09-28 本轮只读复核：本机主页面 HTTP 200；隧道 readiness 显示 4 个连接；从本电脑访问公网 HTTPS 未完成连接（状态 000）。这不能证明手机网络同样失败，不能归因为证书损坏，也不能宣布外网已修好。继续分层定位 HTTPS；若尚未可达，明确保留该阻塞项，不给出“手机已可用”的结论。

保留主仓库及 realtime-voice 工作树现有未提交修改。只移植必要语音组件，不整树覆盖或合并。部署前确认没有活动任务，再做受控重启；不重启承载其他服务的隧道，不改 C 盘 OpenClaw，不推送仓库或发送外部通知。

## 实施与验收

1. 先补失败测试：鉴权、票据过期与重放、来源校验、会话绑定、上下文上限、连接限额与关闭清理。
2. 实现主服务独立语音桥与聊天面板；验证转写、静音、打断、挂断和录音互斥。自动测试不得消耗真实模型额度或操作真实工作产物。
3. 使用隔离工作空间运行 `npm run verify`，完成类型检查、非线上目录构建及改动前端的 Impeccable 检查。浏览器检查窄屏布局及模拟音频流程；模拟结果不代替真机验收。
4. 部署后核对服务进程、实际资源指纹、认证拒绝路径及 HTTPS/WSS 接入。不在页面加载时发起付费通话。
5. 用户在手机上手动开始通话，验证能听见回答、能收音、能打断、挂断后不再收音；手机切后台后状态与设备释放正确。用户试听前只能报告自动验证结果，不能宣称音质与移动网络体验通过。

## 自检

本方案明确区分当前聊天试听接入、独立实验室及完整任务协调。没有新增匿名入口；凭据不传到 URL；上下文、并发与通话生命周期有界。公网 HTTPS 与真人手机音频是独立验收条件，任一未完成均如实说明。
