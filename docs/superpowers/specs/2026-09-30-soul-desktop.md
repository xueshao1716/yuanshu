## 电脑操作的明确边界

这是独立的 Windows UI Automation 适配器，不包含 Codex 私有运行时、凭据或能力转授权。
仅允许本机已认证页面选择现有会话与特定窗口，授权 10 分钟，修改逐步确认，观察结果限时且单次使用。
允许名单为 Windows 安装位置且 Microsoft 签名有效的记事本、计算器、画图、写字板；不支持浏览器、终端、密码框、坐标、全局按键、剪贴板和任意脚本。
支持的动作取决于窗口实际暴露的 Invoke / Value / Scroll 控件模式。现代记事本可能只提供 TextPattern，不能因此声称输入能力已经实测。
操作结果无法确认时撤销授权，要求人工核对，禁止自动重试。

真实桌面兼容性验收尚未完成，界面已标明“受控试用”。本轮没有向真实桌面输入、调用付费模型或读取用户文档。
