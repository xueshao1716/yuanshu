# 培养证据观察补齐：首批接入设计草案

日期：2026-10-01。状态：研究后的具体方案，等待用户审阅；未实施、未部署。

前置依据：[旧系统机制取舍核查](../../verification/2026-10-01-legacy-mechanism-assessment.md)；继续遵循 [培养生态设计](2026-09-30-agent-cultivation-ecology-design.md)，不重写其中的权限、身份与学习治理。

## 1. 目标和范围

让用户在现有“她的培养空间 → 学习证据”里看明白一项经验从哪里来、经历了哪些处理、哪些事实还不知道。吸收旧系统的来源链理念，但完全使用元枢已有记录。

首批只增强证据投影与呈现。不新开培养主页，不另建成长数据库，不调用模型或扫描私人目录，不增加调度器、评分、自动纠偏、基因变更、运行时接入或学习授权。

小语的培养理念、具体人物及表达方法仍由小语真实提交；工程侧不代写人格或假造样本。

## 2. 采用方案

使用现有 `/api/cultivation/experience` 分页读取及关联知识记录，新增纯投影字段；前端就地呈现来源链和当前页摘要。沿用现有身份认证、分页、错误处理及知识详情入口。

不选整体导入旧系统：存在身份、目录、默认分数和治理冲突；不选再造独立观察库：会增加失同步风险。需要长期分布分析时再设计采样与授权，不从本页倒推全历史。

## 3. 数据契约与事实边界

扩展 `engine/cultivation/experience.mjs` 的返回项，保留现有字段兼容性。新增 `observation`：

- `lineage`：`agentId`、`designId`、`runId`、`knowledgeJobId`，从校验过的运行记录取得；补证关联有效时才附 `resolutionJobId` 和 `entryId`。
- `linkState`：`linked` 或 `invalidated`，沿用 job.runId 与 outputHash 的现有一致性检查，不扩大其证明范围。
- `generatedRole`：固定为 `model_generated`，表示来源属性而不是健康或质量判断。
- `resolutionRecorded`：是否存在关联的补证记录，不改名为“证据已通过/当前有效”。
- `sourceCurrent`：首批固定为 `not_checked`，明确读取此页面没有重新获取或核验独立来源。
- `latestDecisions`：按采用作用域选取已记录的最新决定，保留 decision、actor.kind、at、version 与 entryId；仅为历史决定，不推定当前可注入、人格已改变或用户认可。
- `userAcceptance`：保持 `null`。人工签名采用一项知识不自动等于对所有输出内容的认可。

运行与知识关联失效时，补证和采用投影不输出历史缓存，显示失效原因。已有 run 来源标识可以保留并注明只代表运行记录。

新增分页 `coverage`：`basis: returned_page`、`returnedCount`、`hasMore`、`observedAt`。所有摘要计数只针对返回页，不宣称全局总数、今日总数或完整历史。`observedAt` 仅为投影时间，不是原始来源核验时间。

读取期间关联记录变化不构成跨库事务快照。服务端返回的 revision/各项知识 revision 继续用于既有并发校验；UI 注明页面可能随任务进展变化。任何采用操作仍以写入前重新核验为准，观察投影不得成为授权依据。

## 4. 页面行为

现有“学习证据”页顶部显示当前页：候选数、带补证记录数、有关联失效数。只展示计数，明确分类可重叠，不做完成率或健康分。

每条记录显示“个体 → 设计版本 → 任务 → 知识候选”；点击现有知识入口查看补证详情，不另做一套知识编辑器。保留原有采用/退役操作与人工签名流程。

采用记录继续区分母体与原个体；“曾采用”与“当前允许注入”不混为一谈。提示“来源当前有效性未在本页重核，采用时由服务器复核”。

不展示原始凭据、私人绝对路径和完整任务正文；不新增原始记录外发。UI 文本必须作为普通文本渲染。

空页明确“本页暂无记录”。读取失败不显示 0、不显示正常；若保留上次成功的数据，必须标明旧数据及时间。分页冲突沿用回到第一页并重新读取的交互。

## 5. 性能、隔离与兼容

- 不额外扫描所有运行；复用当前页及已批量读取的知识记录，单页最多 50 项。
- 不读取新的磁盘目录、不新增 GET 写入副作用、不主动启动运行器。
- 沿用现有 30 秒轮询策略；页隐藏或离线不轮询，无新增并行轮询源。
- 不重初始化母体 gene/emotion 单例，不用母体会话快照冒充孩子状态。
- 旧字段 `evidenceCount` 继续表示模型输出本身不构成独立证据，不改为补证数量；新呈现优先使用语义明确的 observation 字段。
- 本批不更改资源页“尚无独立土壤观察结论”的真实性表述；不能交付来源链后就宣称完成情绪健康观察。

## 6. 验收条件

1. 空记录、未关联、关联失效、已有补证、不同作用域采用/退役均有明确显示。
2. job.runId 或 outputHash 不符时，不显示为有效补证或可用经验；不泄漏关联记录正文。
3. resolution 存在或历史决定为 adopt，也不能显示“当前有效”“用户认可”或“成长完成”。
4. 同一记录翻页、刷新、重启后仍指向同一个体、设计、任务和知识候选，不串到其他个体。
5. 摘要严格等于当前页记录，未加载页不计入；分类重叠不被画成互斥占比。
6. 读取只访问已有分页/知识接口；没有额外模型、网络、源文件核验或业务状态写入。
7. 既有证据门、签名采用、母体学习权限及退役行为回归通过。
8. UI 覆盖窄屏、长 ID、空态、失败态、旧数据警告及分页重试；不增加拥挤的新主页。

实现时先写投影/失效/无副作用测试，再接前端；运行隔离 `npm run verify`、针对改动组件的界面检查，并读取实际页面验证。未运行这些验收之前不得声称接入完成。

## 7. 明确留在后续的事项

任务来源与表达分布观察，需要时间窗、个体作用域和真实采样，不能照搬旧六类关键词/40% 阈值。记忆去重候选需保留互相矛盾的事实和来源版本，不按前缀相似度直接合并。二者另行设计，不作为本批暗藏范围。

未请求启用任何旧程序，未授权将研究结果自动送入人格/记忆。代码实施及合并发布待本草案确认；本次无版本变更、构建、重启或推送。
