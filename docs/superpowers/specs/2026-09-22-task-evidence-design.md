# 真实任务验收与进化证据

用户已同意先做实真实任务验收、任务覆盖和效果展示，不再增加新的进化框架。本轮沿用当前工作区，保留先前尚未提交的更改，不推送、不代替用户验收真实产物。

## 设计

进化页新增真实任务验收与策略进度面板。任务从持久化运行记录读取，工具选择从同一次运行的成功工具事件提取，不使用全局最后会话猜测。任务执行状态、人工验收、技能学习资格分别展示。

验收绑定运行事件、任务输入和本地交付文件内容摘要。用户查看结果后给出合格、有问题或撤销；合格只允许已完成且有可核对结果的任务。关联文件缺失、越界、链接、过大或仅有远程交付时，不提供合格入口。服务不下载远程资源、不执行模型给出的命令。记录限量、原子写入，双页面通过版本号防覆盖，保存最近更改历史。

只有合格验收中明确勾选、且运行记录证明成功加载的技能，才能转成技能匹配样本。任务合格本身不证明某个技能选择正确。不把真实任务验收混入修复重试轨迹，不把合成实验算作真实任务。后续内容变化、撤销或有问题会让该样本退出评分。天团使用原有审批事实，不通过通用任务入口接受天团终稿。

状态页展示观察数、合格数、可评分记录和去重任务组，以及发现/保留验收、后续观察、试运行、启用或回滚的当前阶段与原因。至少八组任务只是必要条件，不能用数量满足推断候选有效。各类任务覆盖只代表记录分布。

## 验收

隔离测试覆盖文本、图片、文档、代码交付，成功/失败/未完成工具，任务间隔离、文件变动、撤销、并发旧版本、异常路径和虚假技能标签。现有进化周期测试证明新样本经原闸门处理。浏览器以隔离服务验证提交、刷新、失效和手机布局；生产只读检查，不给用户历史任务伪造合格标签。全量测试、类型、构建、界面检查后部署网页服务。
