# 网站工坊重做

用户已在本会话批准 GrapesJS 编辑底座、原创三风格模板、选中区域 AI 修改的方案。MotionSites 作为审美参考，不复制其付费内容。

## 范围与交互

- 保留界面工坊入口及旧 M3E 作品；新作品采用独立 website-projects 存储。
- 三个可立即编辑的原创单页模板：全幅影像、杂志排版、科技动态。标题/正文/图片/链接/样式可点选编辑，区块可拖动，支持撤销、重做和手机预览。
- 新建即保存模板版本，不依赖模型；AI 根据本作品需求生成一个候选版本，不自动替换当前画布。
- 选中元素后 AI 只替换指定子树，保留根 ID、其他元素和全局 CSS。整页设计为单独明确按钮。
- 保存单页的规范 HTML/CSS（可重新解析为 GrapesJS 组件），版本不可变；本地草稿保存供意外刷新恢复。首版不承诺任意 React 项目或业务脚本导入。
- 后台任务提供有时间戳的真实阶段：准备、等待模型、校验、修正、保存、完成/失败/取消。重连可读取状态；一个项目最多一个任务；失败不丢现有版本。
- 导出安全静态 HTML，分享复用现有 share_project 实现，失败明确反馈。用户点击分享才发布。

## 边界

生成 HTML 不运行脚本，清除事件属性、嵌入页面、表单提交和危险 URL；CSS 经解析验证。画布禁用组件脚本，预览 sandbox 空权限。只保存规范 HTML/CSS，不盲信编辑器内部任意脚本元数据。

## 验收

隔离临时目录验证不可变版本、局部修改边界、恶意 HTML/CSS、取消、重启中断、失败/修正阶段和导出。真实浏览器验证选模板、文字/图片/样式编辑、撤销、保存、刷新恢复、AI 局部修改、预览和导出。运行类型检查、全量测试、构建及设计扫描。升级版本、重启验证服务，再按仓库约定双推；不发送微信通知。
