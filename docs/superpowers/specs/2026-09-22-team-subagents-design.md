# 天团与子任务整合

用户已授权实施。普通聊天中的角色标题不能证明执行；现有视频天团也有独立的模型调用路径。

采用同一个 spawnSubagent 生命周期执行器。通用天团按方案、质疑、成稿、复核串行执行，质疑和成稿拿到此前完整的有界结果。复核只接收当前成稿、原始要求、会话事实和程序检查结果，不重复继承前两位角色的建议，避免审查被先前结论带偏和重复处理。复核不通过最多修订一次；模型复核与人工验收分开。失败和取消立即停止，不伪装为成功。

复核采用中等推理并保留240秒上限。明确秒数及带引号口播的镜头先做每秒四字的下限检查；计算排除未填写字段和字幕，分支分别核对。程序能确认的超时必须修订，模型自报通过不能绕过；未知字段、未识别格式、时序预算和事实真实性仍由模型及用户审查，未发现算术问题不代表内容合格。

思考档位按模型能力适配：支持medium时使用medium；声明medium不可用时向下选受支持档位，不能自动升级为high。当前GLM实际发送low，GPT实际发送medium。服务商403明确失败、不自动重试或切换账号；真实评测逐步记录实际请求档位和响应用量。

通用天团作为普通会话工具 delegate_team 提供给两个引擎，同时提供明确的工作台入口。宿主负责写交付文件、关联父任务和会话；模型不能提供关联身份或任意输出路径。子角色当前仅能分析和写正文，命令、媒体生成仍由主角色调用受控工具。

工作台新任务默认通用协作，可切换原有视频专用流程。通用交付走任务验收；视频交付保留原送审。角色标签不成为技能学习标签。台账记录实际模型、开始/结束、错误及结果摘要。

验证覆盖真实模型调用、上下文传递、失败阻断、取消、身份边界、重复恢复和最终交付；使用隔离工作区，不拿用户已有作品做测试。
