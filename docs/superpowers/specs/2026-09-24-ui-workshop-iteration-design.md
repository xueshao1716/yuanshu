# 界面工坊：复用 M3E 的作品迭代

用户已认可作品绑定、候选方向、局部修改、预览及回退；本轮明确复用原有 M3E Canvas。

## 现状与边界

上游 lnkiai/m3e-canvas (MIT, d2bc92c) 静态包具备组件草图、AI 绘制、交互预览、JSON 导入导出。当前只保存在浏览器的单一文档，主站迁移令牌后壳仍读取旧 key，可能出现假性“无模型”。这不是 Figma，也不是任意 HTML 编辑器。

## 实现

- 创作 / 界面工坊展示作品列表及详情，不再自动跳走。每件作品绑定需求与用户填写的素材说明；不扫描聊天、经验库或其他作品，不擅自读路径或抓远程素材。
- 作品落在 workspace/workshop-out/ui-designs；随机 ID、原子写入、只允许自有 JSON，拒绝路径穿越和符号链接逃逸。保存不可变版本，当前版本是显式选择的指针。
- 一次后台任务生成两个方向，各自保存，失败保留已成功结果。服务端执行不依赖浏览器轮询存活。重启中断明确显示；有界模型超时；同作品不并发生成。
- 局部修改明确选择一个组件组，仅替换该组；帧、主题、其他组由服务端保留。结果成为候选版本，不直接覆盖当前版本。
- 打开版本将服务器文档初始化到作品/版本专属浏览器草稿；直接访问版本地址时，缺失草稿自动从服务器恢复。给静态包做可重复的最小键名适配，使不同作品/版本的草稿和编辑锁隔离。壳补“保存新版本”“返回作品”，防止未保存离开；旧匿名草稿原位保留。
- 模型使用显式选择，失效时报错，不默默换默认。壳适配现行登录令牌，模型名称用 DOM 文本创建。版本记录实际模型；不把结构校验标为视觉验收。
- 预览复用原画布“预览 (P)”；作品页列出结构验证状态。JSON 导出仍可用；HTML 生成和 Figma 接入不在此版。

## 验收

临时工作区验证版本不可变、跨作品拒绝、非法文档/素材地址、局部编辑边界、后台生成与部分失败、重启识别。真实模型生成两方向、局部修订、版本回退；浏览器走创建→打开→保存→返回，桌面与手机布局。四件套结果及已知基线失败如实记录。
