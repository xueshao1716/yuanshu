# AIBody 有证据的学习闭环（首批）

状态：依据用户认可的架构纠偏方向实施；开发不等于部署。

## 边界

母体持有持续身份、学习决定与个体关系，宿主负责执行和展示。本批复用培养账本和知识证据链，不引入平行人格库，不导入旧私人记忆，不修改身份、基因基线、工具权限或人物设计。

## 行为

1. 成功、未完成、取消、结果不明的培养任务均留下可追踪记录。运行状态只证明发生过什么，不证明模型结论或失败原因；原始异常、凭据不进入经验正文。
2. 新授权项 `motherLearning` 默认 false。主人签名启用后，母体可以决定采用自己所属、就绪且具有知识数据授权的个体经验；仍须先有独立来源提交、来源当前有效，且不改变任何受保护设置。母体不能自批授权。
3. 撤销策略、暂停个体、撤销数据范围或来源失效后，后续检索立即停止。模型身份与授权在异步操作前后均核查；变更竞态失败关闭。
4. 文本对话在真实母体身份绑定后取用已采用知识；最多五条、受现有字节预算限制、不可信引用格式。仅提供不算使用，回复出现对应引用才记“引用”，不推断正确性、成长或用户认可。
5. 面板展示真实授权和运行结果，继续指向同一份知识账本。声音、外貌、服装及各个体隔离保持原状。

## 验收

- 默认拒绝自授权，显式授权允许；外来母体、其他个体、过期/撤回/竞态均拒绝。
- 无独立证据不能采用；来源变化、退役后上下文移除；重建运行时后保持账本决定。
- 中断不冒充失败；失败记录不自动升级成知识；重复同步不重复登记。
- 自动上下文只给当前真实母体，引用使用记录不等于成效，降级不阻断聊天。
- 定向回归、隔离全量测试、类型检查、非线上构建；如改面板则检查现有界面规则。

## 后续而非本批承诺

跨宿主可携带的母体核心、长期关系与情感多样性评估、独立学习效果实验，需要后续增量实施；本批不把引用次数当成长指标。
