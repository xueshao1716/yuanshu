# 第四项首期：行为实验记录

日期：2026-09-26。范围：仅实现已确认的 Q4 证据连接层。当前状态：源码、定向测试及隔离全量回归通过；未部署。

## 能做什么

- 显式关联同工作空间、同会话的原做法与最多两个替代做法；每个做法引用不同的已有运行和调用者声明的做法版本。版本名只是标签，实际执行版本以来源及产物指纹为准。
- 从运行账、事件和既有人工验收读事实，不接受调用者上传“实际模型”“评分”“已提升”等结论。文本模型、媒体模型、执行引擎分开保存；未知为 null 或空列表。
- 保存失败、截断和部分用量观测。费用不汇总、观察事件不直接相加，因为可能是累计量或重复上报；总费用 null、完整性 false，不按零收费解释。
- 原始任务、运行信息、产物或验收变化时，详情转 stale；原快照保留。没有对照或独立验收则 incomplete，存在失败则 failed。
- comparable 仅表示现有比较材料满足首期条件，不代表更好；adoptionEligible 和 improvementProven 始终 false。
- 同一实验幂等；不同输入冲突409。跨进程工作空间锁与原子重命名避免并发丢记录；撤回用 revision 校验并保留旧版本状态和失败材料。
- SHA256 检查持久记录损坏，不是对有本机文件权限攻击者的签名或操作系统沙箱。原子替换测试覆盖重命名失败，不承诺断电后的硬盘持久性。

## 显式接口（统一鉴权）

- `POST /api/behavior-experiments`：创建；请求体≤256KiB。
- `GET /api/behavior-experiments`：有界索引及 real-task/synthetic-fixture 分组计数；列表不宣称材料当前有效，需读取详情。
- `GET /api/behavior-experiments/{id}`：读取并核验来源当前指纹。
- `POST /api/behavior-experiments/{id}/revoke`：传 revision/reason 撤回；请求体≤10.24KiB。

创建字段：`experimentId`、`sourceKind: "real-task"`、`sessionId`、`hypothesis`、`baseline: {runId, version}`、`variants: [{runId, version}]`。不接受任意目标文件或自报验收。记录ID由服务生成，不能当路径传入。

存储：工作空间 `记忆/运行时/行为实验/{id}.json`，最多200条、单记录≤256KiB；满额拒绝，不自动删除失败。现有来源读取上限：运行2MiB、事件4MiB、单产物8MiB/每次产物检查总量24MiB。这是记录读取界限，不是对已有任务施加执行预算。

HTTP入口不开放合成样本；隔离测试通过服务构造选项显式开启。单元测试里的 real-task HTTP 协议样例依旧是临时夹具，不计作生产真实任务证据。
