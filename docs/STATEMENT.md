# 元枢 · 系统介绍与声明

> 这一页是**系统的自我介绍与边界声明**，也是她在产品里对自己身份的公开说明。
> 界面位置：系统 → 关于元枢。代码位置：`frontend/src/pages/System.tsx`。

## 一、这是什么

**元枢（Yuanshu）是一套装在你自己电脑上的 AI 工作台。** 和你对话的智能体叫**小语**：她有固定人格、长期记忆和情绪状态，每天夜里复盘自己，把经验写回记忆与技能；她有手，能读写文件、跑命令、出图做 PPT、按时自己干活。

- 不是又一个云端聊天框：模型可以接云端，但**会话、记忆、文件、密钥都在你的硬盘上**
- 不是一套需要你伺候的框架：装完、填一个 Key，就能开始用

## 二、三条设计原则

1. **数据主权在你**。工作区、记忆、密钥都在本机；服务只监听本机（或你显式开放的局域网），令牌只存本机浏览器。
2. **权力分层，而不是一刀切**。她能做的事按风险分级：写文件/跑命令在自主范围内；花钱有额度、每笔留理由；**对外发布、改人格、动密钥永远要你点头**。
3. **每一次改变都可回退、可核对**。人格改动走草案 → 批准 → 可回滚；自主动手写 `文档/自主执行审计.md`；花钱写 `文档/花费审计.md`；改动效果写 `文档/harness-试验.md`。

## 三、她能自己决定什么（会随你的配置变化）

默认边界（`记忆/运行时/自主执行.json`）：

| 能做 | 仍要你点头 |
|---|---|
| 写工作空间内的文件 | 对外发布 / 分享到外网 |
| 跑本机命令（红线命令仍走审批） | 改人格定义、改她自己的权限 |
| 本地 git add/commit（不含 push） | 动你的密钥与凭据 |
| 构建与测试 | 超出额度的花费 |
| 在额度内花钱出图/出片 | |

额度（默认）：单次 ¥30 / 每日 ¥200 / 每月 ¥2000。

## 四、她不是什么

- **不是全自动代理**：她的自主范围由你配置，越线会停下来问，不会偷偷做。
- **不是无记忆的工具**：她有自我描述（`记忆/自我.md`），知道自己在哪、活了多久、能做什么、拒绝什么。
- **不改写历史**：自我描述每次按真实状态重算，她没有能力给自己编一段更好听的过去。
