# 聊天串素材与生图画幅修复验收

日期：2026-09-23。源码版本：2.115.9。修复验收后，用户追加授权提交并双推；本次同步前端快照，不重新打包客户端，不外发通知。推送状态以远端提交核验为准。

## 根因与改动

1. 后端曾从所有工具输出中抓取媒体路径，前端也从工具文本提取视频。读取协议或经验库时，旧素材路径被当成本轮交付；本地派生附件缓存使污染刷新后仍存在。
2. generate_image 的工具参数原来只有 prompt，执行链路没有传 size，因此多次请求实际都使用默认方图。不能据此认定 agnes 不支持竖图。
3. 普通生图还可能被附加默认自画像的人物特征词，现在仅默认自画像模板使用这类变化。

修复：只接收成功工具的显式 media 结果，不再自动投递任意工具文本中的路径；保守过滤可证实来自只读工具的旧回放和缓存。后台读取加生成的混合命令不算只读，新增测试已先红后绿。

画幅参数 size / aspect_ratio 贯通聊天生图链路。明确参数优先，兼容提示词的比例与像素说明；冲突参数提前报错。读取返回图片的真实像素，分别记录请求、实际尺寸、严格/近似匹配或未核验，不允许把裁切当成原生画幅达标。
