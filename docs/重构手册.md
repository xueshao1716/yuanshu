# 重构手册（模块搬迁/拆分）

2026-11-05 到 11-06 两天里做了 7 次域迁移、3 次文件拆分。这里是**踩过的坑和固定套路**，下次照做。

---

## 一、域迁移（`engine/<prefix>-*.mjs` → `engine/<domain>/*.mjs`）

固定四步，每步都要跑：

```powershell
# 1. 移动 + 重算引用
node D:\deepseek\migrate-domain.mjs <前缀> <域>

# 2. 补残留（按旧文件名兜底，覆盖 ./, ../, 裸名三种写法）
node D:\deepseek\fix-domain-refs.mjs <域> <前缀>

# 3. 模块级校验（这一步最有用，能抓出所有漏改）
node --input-type=module -e "await import('file:///D:/pi-web/server.mjs')"

# 4. 域测试
node --test --test-concurrency=1 tests/unit/*<域>*.test.mjs
```

### 必踩的四个坑

| 坑 | 症状 | 解法 |
|---|---|---|
| 同级依赖断裂 | `Cannot find module './trace.mjs'` | 按「原位置 engine/」重算相对路径 |
| 跨层引用偏移 | `../shared/` 变成 `engine/shared/` | 按 engine → 域目录 → 仓库根 依次解析 |
| 只 re-export 不 import | 运行时 `xxx is not defined` | **主文件内部还在用的必须同时 `import`** |
| 批量改写误伤测试 | 断言里的字符串被改成相对路径 | 只改 import 语句，不要对任意字符串做正则替换 |

## 二、文件拆分（大文件 → 多个小文件）

### 先扫描依赖，再动手

```powershell
node D:\deepseek\scan-manager.mjs      # 列出每个函数用了哪些模块级状态/导入
```

**判据**：`state=-` 且 `imports` 很少的函数，才能安全抽出。有状态的（如 `_cwd`、`_SessionManager`、`lifecycle`）必须连状态一起搬，或先做依赖注入。

### 两类拆法

1. **薄处理层**（HTTP handler）：机械搬运，在子文件里补齐 `json`/`readProject` 等依赖即可。
2. **纯函数层**：零状态，直接搬；搬完主文件要同时 `import`（见上表第三行）。

### 不要拆的东西

闭包套闭包的核心编排（如 `createStoryOrchestrator` 1285 行）——里面几十个方法共用同一批闭包变量，拆它要先把状态搬进上下文对象，是独立工程，不是顺手能做的。

## 三、前端组件分组

```powershell
node D:\deepseek\group-components.mjs <子目录> <文件名正则>
node D:\deepseek\rebase-subdir.mjs <子目录>     # 子目录内部依赖按原位置重算
```

**tsc 是最好的验证**：`npx tsc --noEmit` 会精确指出每一处漏改。

### 测试有三种路径写法，都要改

```js
read('components/TeamRunView.tsx')                    // ① 单个字符串
read('components', 'MoodPanel.tsx')                   // ② 分段
path.join(ROOT, 'frontend', 'src', 'components', 'X') // ③ path.join 分段
```

只改 ①② 会漏掉 ③，症状是 `ENOENT: no such file`。

## 四、部署（每次必做，顺序不能变）

```powershell
# 1. 整目录同步（不要跳过任何已迁移的域——它们仍会被后续改动波及）
robocopy "D:\pi-web\engine" "$dst\engine" /E /NFL /NDL /NJH /NJS /R:1 /W:1 /XD node_modules .worktrees py

# 2. 前端产物
foreach ($d in @("frontend\dist","public","app\dist")) { robocopy $d "$dst\$d" /E /NFL /NDL /NJH /NJS /R:1 /W:1 }

# 3. 重启 + 探活（启动慢，第一次失败等 5 秒再试）
node scripts\release-restart.mjs
Invoke-WebRequest http://127.0.0.1:8787/api/health
```
