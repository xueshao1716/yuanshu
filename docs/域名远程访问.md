# 远程访问：用你自己的域名

> 2026-11-06 · 前提：你有一个阿里云域名。目标：手机在外网稳定访问家里的元枢。

## 一、先明确一件事

域名本身**不能**让内网服务可从外网访问。域名只解决「**名字好记 + 地址稳定**」，
真正把流量送进来的还是下面三条路之一：

| 路 | 需要什么 | 结果地址 |
|---|---|---|
| A. Cloudflare Tunnel | 域名托管到 Cloudflare（免费）+ 本机 cloudflared（已装） | `https://yuanshu.你的域名.com` ✅ HTTPS 自动 |
| B. frp + 云服务器 | 一台有公网 IP 的机器（阿里云 ECS 最低配即可） | `https://yuanshu.你的域名.com` |
| C. IPv6 + DDNS | 运营商给公网 IPv6 + 路由器放行 | `http://yuanshu.你的域名.com:8787` |

**你现在的情况**：没有公网 IPv6（`/api/net/reachability` 里 `ipv6 global: 无`），所以 C 暂时走不通。

## 二、路 A：Cloudflare Tunnel（推荐）

### 为什么推荐

- **域名不用搬走**：只需要把 NS 改到 Cloudflare（免费套餐），阿里云那边保留域名所有权
- **手机什么都不用装**：浏览器直接开 https 地址
- **证书自动**：不用自己搞 Let's Encrypt
- **地址永久固定**：重启不变

### 步骤

```powershell
# 1. 登录（会弹浏览器，选你的 Cloudflare 账号）
cloudflared tunnel login

# 2. 建隧道（名字随便，比如 yuanshu）
cloudflared tunnel create yuanshu
#    记下输出的 Tunnel ID

# 3. 把域名指到隧道（把 yuanshu.你的域名.com 换成你要的）
cloudflared tunnel route dns yuanshu yuanshu.你的域名.com

# 4. 写配置 %USERPROFILE%\.cloudflared\config.yml
```

```yaml
tunnel: <Tunnel ID>
credentials-file: C:\Users\xuexiaofeng\.cloudflared\<Tunnel ID>.json
ingress:
  - hostname: yuanshu.你的域名.com
    service: http://127.0.0.1:8787
  - service: http_status:404
```

```powershell
# 5. 跑起来
cloudflared tunnel run yuanshu
```

**6. 手机打开** `https://yuanshu.你的域名.com` → 填 token。

### 前置：把域名 NS 改到 Cloudflare

1. Cloudflare 控制台 → Add site → 输入你的域名（免费套餐）
2. 它给你两个 NS，例如 `xxx.ns.cloudflare.com`
3. 阿里云域名控制台 → 域名 → DNS 修改 → 改成这两个 NS
4. 等生效（几分钟到几小时）

**注意**：改了 NS 后，**阿里云那边的解析记录全部失效**，需要在 Cloudflare 里重新加（Cloudflare 会自动扫描导入）。

## 三、路 B：frp + 阿里云 ECS

如果你**不想把域名交给 Cloudflare**，或者已经有 ECS：

```
手机 → your-domain.com:7000 → 阿里云 ECS(frps) → 你家里电脑(frpc) → 8787
```

- 成本：ECS 最低配（约 60-100 元/年，学生机更便宜）
- 需要备案才能用 80/443（用非标端口可以绕过）
- 配置比 A 复杂，但**完全自己掌控**

## 四、路 C：IPv6 + 阿里云 DDNS

等运营商给了公网 IPv6 之后：

1. 阿里云云解析 → 添加 AAAA 记录：`yuanshu.你的域名.com → <你家的 IPv6>`
2. 写个定时任务，IP 变了就更新 AAAA（阿里云 OpenAPI `UpdateDomainRecord`）
3. 路由器放行 8787 入站

**优点**：真正直连，速度最快，不经任何第三方
**缺点**：要等运营商 + 要动路由器 + 要写 DDNS

## 五、我的建议

```
现在：路 A（Cloudflare Tunnel）—— 一小时能搞定，地址稳定，手机零安装
将来：如果运营商给了 IPv6，再切路 C（最快，且完全私有）
```

## 六、安全（无论哪条路）

公网可达之后：

1. **token 必须换掉默认值**，且足够长
2. 建议开 Cloudflare 的 Access（免费版可加邮箱白名单）——这样只有你能进
3. 定期看 `记忆/运行时/服务日志-*.log` 有没有异常请求
