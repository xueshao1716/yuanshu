# 公网 IPv6 直连：手机不装隧道直接连家里电脑

> 2026-11-06 · 目标：手机用流量（不在同一 WiFi）直接打开家里的元枢，不需要内网穿透服务。

## 一、先确认三件事（缺一不可）

| 条件 | 怎么确认 |
|---|---|
| ① 运营商给你公网 IPv6 | 手机用流量访问 https://test-ipv6.com ，看到一长串 `2408:...` 且得分 ≥ 18/20 |
| ② 家里网络也有公网 IPv6 | 电脑上打开同一个网站，确认也拿到 IPv6 |
| ③ 电脑监听在 IPv6 上 | 元枢的 `GET /api/net/reachability` 里 `dualStack: true` |

**① 不满足就没戏**：IPv4 公网地址运营商基本不给了，IPv6 是唯一免费路径。

## 二、元枢这边（已改好）

`config.mjs` 里 LAN 模式现在绑**双栈**：

```js
host: env("HOST") || (env("LAN") === "1" ? "::" : "127.0.0.1")
```

启动：

```powershell
$env:LAN = "1"
node server.mjs
```

查本机地址：

```
GET /api/net/reachability
```

返回里会告诉你：

- `ipv6` 列表：标了哪些是 `global: true`（公网可用）
- 每个地址直接给出可用 URL：`http://[2408:xxxx::1234]:8787`
- `hint`：当前绑定是否支持 IPv6

## 三、路由器放行端口（关键一步）

Windows 上开了服务还不够，**路由器默认拦入站**。

1. 登录路由器（一般 `192.168.1.1`）
2. 找到 **IPv6 防火墙**，新建规则：
   - 方向：入站
   - 目标：电脑的 IPv6 地址（或 MAC）
   - 端口：8787（或你改的端口）
   - 协议：TCP
3. 如果路由器有「IPv6 防火墙总开关」，需要允许入站（有些型号默认全拦）

## 四、手机端怎么连

浏览器或客户端里填：

```
http://[2408:xxxx:xxxx::1234]:8787
```

**注意方括号**——IPv6 地址在 URL 里必须用 `[]` 包起来，否则冒号会被当成端口分隔符。

然后填 token（设置页可看）。

## 五、IPv6 地址会变，怎么办

运营商前缀通常**几天到几周变一次**（重新拨号就变）。三个办法：

| 办法 | 说明 |
|---|---|
| **DDNS** | 路由器自带的 DDNS 大多支持 IPv6（如 `xxx.ddns.net`），填域名而不是 IP |
| **元枢自己报** | `GET /api/net/reachability` 随时能查当前地址，变了重新填 |
| **固定后缀** | 部分路由器支持「IPv6 后缀固定」（SLAAC 稳定后缀），前缀变了地址跟域名走 |

## 六、安全提醒（重要）

公网暴露 8787 端口后，**任何人都能扫到它**。必须确认：

1. **token 不是默认值**，且足够长（设置页可改）
2. 服务本身有鉴权（元枢校验 `Authorization: Bearer`，未带 token 一律 401）
3. 不要把端口暴露到不需要的场景：只在需要时开规则
4. 有条件就上 **HTTPS**（自签证书或域名 + Let's Encrypt）——否则 token 在公网上是明文传输

## 七、和隧道方案对比

| | IPv6 直连 | Cloudflare Tunnel 等 |
|---|---|---|
| 依赖 | 运营商给 IPv6 + 路由器放行 | 第三方服务 |
| 速度 | **直连，最快** | 绕一圈，多几十毫秒 |
| 地址稳定 | 会变，要 DDNS | 固定域名 |
| 配置 | 中（要动路由器） | 简单（一条命令） |
| 隐私 | 只有你和运营商 | 流量过第三方 |

**结论**：能搞定路由器就用 IPv6 直连；搞不定或不想动路由器就用隧道。
