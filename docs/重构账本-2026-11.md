## 四、顺手修的真 bug（不只是重构）

| 问题 | 后果 | 状态 |
|---|---|---|
| `notifier.runFinished` 是 async，不该通知时也返回 Promise | 调用方永远走 catch 分支；"短问答不打扰"实际失效 | 改成同步短路 + 异步承接 |
| 异步 `canAccess` 返回 Promise 被当成通过 | **身份校验静默失效** | 改为按拒绝处理并吞掉 rejection |
| `host-identity` 误把 Promise 判断为拒绝 | 随机拒绝，难查 | 同上 |
| 手机「更多」菜单漏了 `gateway`/`plugins` | 手机上根本看不到事务台和插件商店 | 补进 `MORE_ROUTES` |
| 手机用量计数渲染两处 | 顶布局、误触 | 删掉工具栏那份 |
| 安卓启动图标是 Capacitor 模板 | 桌面图标和手机图标不是一个东西 | 用品牌标重生成 5 档 |
| 15 个既有红测试 | 全量测试长期不可信 | 全部转绿 |

## 六、踩过的坑（都已写进 `docs/重构手册.md`）

1. **搬函数只 re-export 不 import** → 运行时报 `xxx is not defined`。出现 4 次。
2. **部署漏拷新子目录** → 服务起不来。出现 2 次（`evolution/`、`knowledge/`）。
3. **批量改写误伤字符串字面量** → 测试断言里的 `'./config.mjs'` 被改成 `'../../config.mjs'`。出现 3 次。
4. **搬完只跑单测不跑真机** → 单测绿、真机 500。出现 3 次。
5. **`.worktrees` 里 36 个孤儿副本**占了 3.86 GB，C 盘告急。
